## 2. §3.2 bigbatch e03b 是否晋级

晋级条件（**同时**满足）：D10 日均 Rank IC 高于 C2，**且**配对 bootstrap 95% CI 不含 0。

| 项 | C2 best | bigbatch e03b best |
|---|---:|---:|
| D10 日均 Rank IC（8 天） | **0.06523** | 0.05247 |
| path_direction | 0.53651 | 0.52578 |
| path_return_mae | 0.05766 | 0.06081 |
| path_return_rmse | 0.08723 | 0.09282 |

配对 bootstrap：Δ IC = **-0.01276**，95% CI = **[-0.03926, -0.00420]**（不含 0，方向为负）。

**判定：不晋级，关线。** 第一项即不满足（e03b IC 低于 C2）；配对 CI 不含 0 且为负，e03b 在这个从未用过的窗口上**显著更差**。

### 2.1 与训练侧的关系

| 代 | val selection_loss | 34 日 D10 Rank IC |
|---|---:|---:|
| clean C03 | 2.2806120 | 0.1200 |
| epoch2（seg 501） | 2.2743811 | 0.0843 |
| **bigbatch e03b（seg 457）** | **2.2616171（最低）** | — |
| bigbatch e03b @ sealed 8 天 | — | **0.05247（最差）** |

e03b 用 global batch 128（64/GPU × 2 T4）+ lr 2e-5 把验证 loss 压到三代最低，比 epoch2 再低 0.0128（-0.56%），**但 OOS 截面排序能力是三代里最差的**。这与 epoch2、C03 的方向完全一致：**clean 线上「验证 loss 下降」与「OOS 排序下降」同向发生，已三次独立证实。** 大 batch + 加倍 LR 在已饱和区域不是解药，是更强的漂移。

按方案 §2 与 §4.3，**e03b 之后不推 e04b**；Small 线只保留 C2 作为 alpha 检查点。
