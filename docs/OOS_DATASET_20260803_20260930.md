## 文件

| 文件 | 说明 |
|---|---|
| `evaluation_samples.jsonl` | 一行一个 `(asof_date, symbol)`；字段见下 |
| `combined_raw.csv` | 2025-07-01 → 2026-10-21 qfq 日线 OHLCVA + `market_cap` |
| `evaluation_manifest.json` | 契约、日期、标签、SHA |
| `README.md` | 字段与使用说明 |

`evaluation_samples.jsonl` 字段：

```text
asof_date, symbol, sector, size_decile, return_10d,
direction, set, start_index, target_date
```

- `return_10d = close[t+10] / close[t] - 1`（**close-to-close**，与旧 OOS 评测口径一致）
- `target_date` = 第 10 个未来交易日
- `size_decile` = 0–9，9 为最大市值；按当日截面 `market_cap` 分位
- `sector` = 84 类申万行业 + `unknown`
