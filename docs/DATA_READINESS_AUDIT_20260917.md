## 关键口径决定

模型条件 `size_percentile` 必须基于与训练一致的“当日全市场市值参考池”，不能基于最终可交易排名池计算。否则 ST、停牌或流动性过滤会改变其他股票的 percentile。

原始训练实现已经确认：`all_a` universe 只按沪深 A 股证券代码前缀筛选，没有排除 ST；`size_percentile` 随后对每个交易日市值有效的全部证券执行 `rank(method="first", pct=True)`。停牌/换手率缺失行使用股票自身已有市值前向填充，行业 unknown 也不影响其参与市值参考横截面。因此生产 size reference 应包含市值有效的 ST、停牌和行业 unknown 证券，以复现模型看到的条件分布。

生产流程应分开维护：

1. `size_reference_universe`：尽量覆盖与训练一致的全市场，用来计算模型条件；包含市值有效的 ST、停牌和行业 unknown 证券，但不要求为这些证券生成预测；
2. `ranking_universe`：经过 ST、停牌、历史长度、流动性等过滤，用来生成可交易排名。

每条预测必须固化 `float_market_cap`、`size_percentile`、reference universe 版本、参考证券数和市值来源。

## OHLCVA 与训练口径审计

### 样本与方法

从 2026-03-27 至 2026-09-17 的120个交易日中选取44只股票：20只按代码稳定抽样、20只取原始收盘价单日跳变最大的证券，并补充平安银行、宁德时代、贵州茅台和招商银行。将 Supabase 当前数据与 BaoStock `adjustflag=2` 前复权数据按证券和日期逐日对齐。

### 单位结论

- BaoStock volume / Supabase volume 的中位比值：100；
- BaoStock amount / Supabase amount 的中位比值：1000。

因此当前 Supabase 使用 Tushare 日线单位：volume 为手、amount 为千元；训练 BaoStock 数据使用股和元。模型逐特征窗口标准化会使全窗口恒定倍数在数学上抵消，但生产输入仍应显式转换为训练单位：

```text
volume_shares = volume_tushare * 100
amount_cny = amount_tushare * 1000
```

不得在同一窗口内混用两种单位来源。

### 复权结论

- 44只全部成功逐日对齐；
- 23只在120日窗口内的原始/前复权 close 比例变化超过0.5%；
- 19只即使各自窗口标准化后，close 最大绝对差仍超过0.1个标准差；
- 严重样本的原始/前复权价格比例变化达到40%-51%；
- 标准化 close 的单点最大差达到约1.30个标准差。

代表性样本：

| 证券 | 原始/前复权比例跨度 | 标准化 close 最大差 |
|---|---:|---:|
| `sz.301283` | 50.91% | 1.12 |
| `sh.603307` | 48.71% | 1.07 |
| `sh.603155` | 47.12% | 1.30 |
| `sz.002335` | 46.21% | 1.16 |
| `sh.600000` | 4.72% | 0.72 |
| `sz.000001` | 3.29% | 0.57 |
| `sh.600519` | 2.37% | 0.32 |

结论：Supabase 当前未复权 OHLC **不能直接用于正式模型推理**。逐窗口标准化无法消除窗口内除权导致的非恒定断点。

### 修复方案

新增 point-in-time 复权因子历史，使用 Tushare 标准前复权公式：

```text
qfq_price(t) = raw_price(t) * adj_factor(t) / adj_factor(signal_date)
```

一次性回填至少120个交易日的全市场 `adj_factor`，以后每个交易日追加当日全市场因子。推理时转换 open/high/low/close，同时将 volume 和 amount 转为训练单位。每个预测 run 固化因子数据最大日期、来源和版本。

### 复权因子落库与最终验收

`public.ashare_adj_factor` 已完成回填：

- 日期范围：2026-03-27 至 2026-09-17，正好覆盖最近120个交易日；
- 记录数：547,946；
- 证券数：4,585；
- 与同期 `ashare_daily_k` 的547,946个 `(code,date)` 全部一一匹配；
- 最新日覆盖：4,559 / 4,559；
- NULL或非正因子：0；
- 重复键：0；
- 主键：`(code, date)`，另有 date 索引。

来源分布：

- `baostock_hfq_close_ratio`：539,798行、4,517只；
- `akshare_sina_hfq_factor`：8,148行、68只；
- 不存在同一股票在窗口内混用来源的情况。

使用下式转换现有原始 OHLC：

```text
qfq_price(t) = raw_price(t) * adj_factor(t) / adj_factor(signal_date)
```

与 BaoStock `adjustflag=2` 最终验收结果：

- 主来源抽取10只高复权风险/代表性股票，共1,200个股票交易日、4,800个OHLC点；最大相对误差 `5.53e-7`，平均相对误差约 `1.44e-7`；
- AKShare备用来源抽取10只，共1,200个股票交易日；9只误差接近浮点舍入，最差样本最大相对误差约0.054%；
- 两种来源均可用于生成训练口径前复权 OHLC；备用来源应设置0.1%的逐点相对误差告警阈值。

结论：复权因子阻塞项已经解除。每日发布前仍需验证当日行情与因子100%匹配、因子为正、窗口内来源不混用，并记录因子来源与最大日期。
