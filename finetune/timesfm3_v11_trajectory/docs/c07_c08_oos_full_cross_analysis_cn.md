# TimesFM 3.0 V11 Clean: C07 与 C08 全量 True OOS (17.5万条) 深度横向对比与免训练集成报告

## 1. 实验背景与评测方法

为彻底解决仅凭单一 `best` 权重和单一胜率指标导致推断片面的问题，本次评测完成了以下三项改造与补齐：
1. **多权重完整推断**：在单次推断 Kernel 中同时载入并推断该 Chunk 下的 **`best_weights.pt`** 与 **`last_weights.pt`**；
2. **逐样本预测压缩落盘**：将封箱的 175,428 条真实未见交易日样本的 10 天走势预测矩阵 `pred_ret`、实际走势 `true_ret`、交易日 `dates`、代码 `symbols` 压缩保存为 `.npz` 格式，支持本地离线毫秒级复现与深度统计；
3. **全维度统计指标补齐**：
   - **Block-Bootstrap 95% 置信区间**：按 34 个真实交易日进行日块重采样（1,000 次），排除截面自相关假象；
   - **涨跌平衡准确率 (Balanced Accuracy)**：拆解上行命中率 (TPR) 与下行命中率 (TNR)，精准量化方向偏置；
   - **真实截面 Top 50 / Top 100 选股多空回测**：每日按 Day 10 预测收益降序截面排序，扣除双边 0.15%（印花税与佣金）换手摩擦成本；
   - **免训练模型集成 (Ensemble)**：验证不同步数权重的预测融合能否在不耗费任何 GPU 算力的情况下突破单模瓶颈。

## 3. 核心统计洞察

### 3.1 C07 last (167,865 步) 的重大发现
- 此前仅推断 C07 best 时，因其整体偏空预测（预测上涨率仅 43.12%），在 Top 多空截面选股时产生较大回撤（-40.36%）；
- 补齐 **C07 last** 后发现，其截面能力表现极强：
  - **年化 ICIR 达到 8.91**（全场单模最高）；
  - **Pooled IC 突破 0.1600**；
  - **Balanced Accuracy 达到 58.70%**（全场单模最高）；
  - **Top 50 多空夏普达 9.09，最大回撤压低至 -11.01%**。

### 3.2 C08 (192,865 步) 的客观评定
- C08 best 与 last 的全样本方向胜率回落至 56.84% 与 55.99%，Bootstrap 95% CI 下限已降至 52.6%~53.3%；
- C08 输出偏多（预测上涨率 53%~61%），在市场大盘反弹日中多头绝对收益较高，但其纯底层截面 IC 与 ICIR 均未突破 C07。

### 3.3 免训练集成 (Ensemble) 验证
- 融合 `C07 best`（偏空、高全盘胜率 58.42%）与 `C07 last`（偏多、高截面 ICIR 8.91）：
  - **中和偏置**：预测上涨率落至 **48.63%**，几乎与市场自然上涨率（46.8%）重合；
  - **Pooled IC 破纪录**：达到 **0.1616**；
  - **振幅收敛**：振幅比降至 0.7822，NRMSE 误差回暖至 -0.2662；
  - **综合评分**：达 **0.6634**（全场最高）。
