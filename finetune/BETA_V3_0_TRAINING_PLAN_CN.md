# Beta v3.0 动态市值条件架构与训练规划

## 版本边界

- Beta v2.0 保持当前已经锁定的训练合同：信号日单点 `size_percentile` 经
  `size_mlp` 映射为 `(B, D_model)`，并在 Layer 10 广播到全部 token。
- Beta v3.0 才引入历史市值百分位序列。这会改变 Dataset、Predictor forward、
  自回归推理和 checkpoint 配置，不能在正在运行的 Beta v2.0 中途混入。
- 本文定义候选架构和淘汰实验，不预设动态市值条件一定提高实盘收益。

## 数据证据

统计直接读取当前固定数据包
`a_share_full_market_v1_beta_symbol_holdout_90_10_v1` 的真实 train/val panel，
窗口合同为 120 日观察、10 日预测。“变化超过 5%/10%”均指市值百分位的绝对
变化超过 5/10 个百分点，不是相对百分比变化。所有统计窗口的120日
`size_percentile` 均完整有效。

| 数据集 | 窗口数 | 首尾变化 >5pp | 周期高低跨度 >5pp | 首尾变化 >10pp | 周期高低跨度 >10pp |
| --- | ---: | ---: | ---: | ---: | ---: |
| 训练集（4,678只） | 9,457,646 | 3,667,541（38.78%） | 7,175,490（75.87%） | 1,584,657（16.76%） | 4,091,780（43.26%） |
| 股票留出集（520只） | 123,982 | 51,596（41.62%） | 97,615（78.73%） | 20,897（16.85%） | 58,638（47.30%） |

训练窗口的120日首尾绝对变化中位数为 3.59pp，75 分位为 7.52pp，90 分位为
13.66pp；120日内高低跨度中位数为 8.86pp，75 分位为 14.12pp，90 分位为
21.56pp。

独立相邻交易日中，训练集单日跳变超过 5pp 的比例仅为 0.171%，超过 10pp 的
比例仅为 0.048%；留出集分别为 0.166% 和 0.042%。因此，大部分120日大变化是
逐步累积的路径，而不是单日异常跳点。当前只输入信号日单值会丢失方向、速度、
持续性和中途反转信息，动态序列具备进入消融实验的充分数据基础。

## 候选输入合同

对每个历史交易日构造：

```text
size_features_t = [p_t, delta_p_t, known_t, observed_t]

p_t          = 当日全市场市值百分位
delta_p_t    = p_t - p_(t-1)，首日置 0
known_t      = 当日百分位是否有效
observed_t   = 是否属于信号日及以前的真实观测
```

Dataset 输出历史120日的 `size_features`，形状为 `(B, 120, 4)`。共享的逐 token
MLP 将其映射为 `(B, 120, D_model)`，与行情 token 按日期一一对齐：

```text
size_condition = size_path_mlp(size_features)
x = x + size_condition
```

`size_path_mlp` 的输出层采用零初始化，使新模型载入父 checkpoint 时动态分支
初始为 no-op。若 `D_cond != D_model`，必须增加显式投影，不允许依赖隐式广播。

## 因果与推理约束

- 历史120日只使用对应交易日已经可得的全市场横截面百分位。
- 未来10日的真实百分位禁止进入训练，即使原始 panel 中存在该列也必须在 Dataset
  边界截断，防止未来横截面泄漏。
- Predictor 在 teacher-forcing 和自回归生成的未来位置统一使用：
  `p_t=p_asof`、`delta_p_t=0`、`observed_t=0`。`known_t` 表示最后已知百分位是否
  有效。训练和推理不得采用不同填充策略。
- 缺失历史百分位使用 `p_t=0.5`、`delta_p_t=0`、`known_t=0`；不得把缺失值静默
  当作真实中盘股。
- 推理端必须保存百分位参考日期、覆盖股票数和数据新鲜度；过期全市场参考不能
  静默伪装为当日数据。

## 架构消融

所有实验必须使用同一父 checkpoint、数据 manifest、股票隔离验证集、随机种子、
优化器、学习率、覆盖顺序和推理参数，只改变市值条件分支。

| 实验 | 市值条件 | 目的 |
| --- | --- | --- |
| A | 无市值条件 | 测量完整 conditioning 的绝对贡献 |
| B | Beta v2.0 信号日单值广播 | 静态市值基线 |
| C | 120日 `p_t` 序列 | 判断历史水平路径是否增益 |
| D | 120日 `[p_t, delta_p_t, known_t, observed_t]` | 判断迁移方向和速度是否增益 |
| E | D + token 级门控 | 判断自适应注入是否优于无衰减相加 |
| F | D 的历史顺序随机打乱，末值保持不变 | 区分路径信息与单纯市值水平 |

门控候选为：

```text
g_t = sigmoid(W_g x_t + b_g)
x_t = x_t + g_t * size_condition_t
```

门控不是默认正确答案。若 D 已稳定优于 B，E 只有在股票留出集继续提高且条件范数
更健康时才能晋级。

## 评估与晋级标准

- Combined objective loss 只作为优化指标，不能单独证明动态市值路径有效。
- 必须比较日频和周频截面 Rank IC、10日收益 Rank IC、方向准确率、分位数组合
  多空收益、换手率和计入交易成本后的收益。
- 按 2025H2/2026H1、市值十分位、行业和市场风格阶段分别报告，避免总体均值掩盖
  大小盘 regime 依赖。
- 记录动态条件输出范数、主干范数和二者比例；若 Loss 改善主要依靠条件能量无界
  放大，不得直接晋级。
- D 必须在股票留出集稳定优于 B，并且时间打乱对照 F 明显退化，才能将收益归因于
  历史路径，而不是额外参数量或当前市值水平。
- 最终候选还必须通过独立时间留出或尚未用于调参的封存测试；当前123,982窗口是
  调优集，不是最终实盘收益证明。

## 实施顺序

1. 将本次统计固化为可重复脚本和带数据 SHA 的 JSON 报告，并增加窗口数断言：
   train=`9,457,646`、validation=`123,982`。
2. 扩展 Dataset，只返回历史120日市值条件，并增加未来条件不可见的单元测试。
3. 扩展 Predictor 和自回归推理接口，加入 shape、mask、checkpoint 配置及
   train/inference 一致性测试。
4. 先跑 A/B/C/D 小规模等预算消融；只有 C/D 显示稳定增益后再投入 E 和全覆盖训练。
5. 完成全覆盖训练、股票留出评估、Rank IC/组合回测和独立时间审计后，再决定是否
   将动态市值序列写入 Beta v3.0 正式模型合同。
