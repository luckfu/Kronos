## 1. 一句话结论

1. **完整锁定 `Kronos-base` 在 `L=20..75` 的窗长峰值与真实内点正则甜点（`alpha = 3e7`）**：
   - 结合 G14（`L60 / L75`）与本实验（`L20 / L35 / L45 / L52`），`Kronos-base` 单模型 65 天 OOS Rank IC 曲线清晰呈现单峰结构：
     `L20 (0.1544) → L35 (0.1719) → L45 (0.1783) →` **`L52 (0.1803, 中性化 0.1262)`** `→ L60 (0.1622) → L75 (0.1362)`；
   - 与 `C2` 等权融合后：**`FUSE_G20_BASE_L45_832` 达 `0.2002 (ICIR 2.26, 100% 正天数, dC2 = +0.0574*)`**，**`FUSE_G20_BASE_L52` 达 `0.2016 (ICIR 2.35, 100% 正天数, 中性化 IC 0.1265 / 1.61, dC2 = +0.0588*)`**；且 `L45` 与 `L52` 在验证集上双双在 **`selected_alpha = 3e7`** 达到内点峰值（`1e8` 回落），彻底闭合了 G14 的正则上界悬念！
2. **`L=45` 跨深度 `[L5, L8, L10]` 与多窗带拼接显著抬升 ICIR（`2.40–2.42`）与 `k=20` 实盘收益（`+18.61%`）**：
   - **`FUSE_G20_BASE_L45_ML_RAW`**（`L=45 [L5, L8, L10]` `2,496d`）：65 天 OOS Rank IC **`0.1964 (ICIR 2.40, 98.5% 正天数, dC2 = +0.0536 [+0.0194, +0.0841])`**，**`k=20` 扣费净收益达 `+18.61%`（`10/10` 赢，最大回撤仅 `−12.57%`，Calmar `1.480`）**，`k=10` `+17.34%`；
   - **`FUSE_G20_BASE_BAND20_52_RAW`**（`[L20, L35, L45(3层), L52]` `4,992d`）：Rank IC **`0.1917 (ICIR 2.42, 100% 正天数, dC2 = +0.0489 [+0.0182, +0.0761])`**；
   - **`FUSE_G20_BASE_L35`**：仅 35 天窗口即取得 Rank IC **`0.1956*`**、**`k=10` 净收益 `+17.93%`（`10/10` 赢，回撤 `−13.22%`，Calmar `1.356`）**。

## 4. 关键科学结论

1. **`Kronos-base` 的最优回看窗口精确落在 `L=45..52`（约两个半月交易日）**：
   - `L=52` 单头截面 IC 最高（`0.1803`、融合 `0.2016`、中性化 `0.1265`），而 `L=45`（及 `L=35`）在 `k=10` 小持仓实盘收益上更具锐度（`+17.68% / +17.93%` vs `L52` `+15.16%`）。
2. **`alpha = 3e7` 是 `stride=2`（`414.4 万` 样本）下 `832` 维单层头的精确最优正则**：
   - 将 G14 的 `1e7` 提升到 `3e7` 后，`G20_BASE_L45_832` 单头 IC 从 `0.1696` 提升至 **`0.1783`**，融合 IC 从 `0.1951` 跨过 `0.20` 门槛至 **`0.2002`**。
