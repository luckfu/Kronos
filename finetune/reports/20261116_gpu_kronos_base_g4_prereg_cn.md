# GPU 探索 G4 Pre-registration：`Kronos-base`（832 维大模型）冻结全市场线性探针与顶层排序微调（2026-11-16）

**状态**：事前登记（早于 G4 GPU Kernel 推送及任何 OOS 计算）。  
**研究纪律**：严格不触碰 `2026-10-24+` 封存验收窗口；仅使用 `train_data.pkl <= 2026-04-30` 训练与累积统计，超参/早停仅看 `val_data.pkl 2026-05-18..2026-07-02`（未见过股票 + 隔离期后），`2026-07-17..2026-10-23` OOS（335,312 行）仅作一次性评估。

---

## 1. 核心假设（跨架构大模型纯量价正交 Alpha）

1. 先前研究已证明：未微调的 `NeoQuasar/Kronos-base`（12 层、832 维、`~102M` 参数）OOS IC（`0.0897`）明显高于未微调的 `Kronos-small`（`0.0589`），且与 `C2` 预测秩相关仅 `0.1265`。`Base` 之所以被停用，仅因**全参数 CE 微调**会在 10 段内摧毁预训练表征（[`20261110_base_clean_collapse_probe_cn.md`](20261110_base_clean_collapse_probe_cn.md) 明确指出可行方向是“冻结主干或只训顶层”）。
2. G1 又刚刚证明：即使只有 `512` 维冻结特征，只要样本扩充到全市场 5,000+ 只股票（`194 万` 行），纯线性头都能把单模型 IC 从 `0.0958` 推到 `0.1427`、融合 IC 推到 `0.1694`、`k=20` 收益推到 `+20.13%`（Calmar `1.881`）。
3. 本实验检验两个从未验证的大模型路径：
   - **`G4_BASE_RIDGE_832` / `G4_BASE_RIDGE_M5`**（GPU 0）：完全冻结 `NeoQuasar/Kronos-base`（无微调、条件头零值，纯量价大模型表征），在全市场 5,000+ 股上提取 `832` 维末位隐状态及 `[h_last, h_m5]` `1,664` 维表征，拟合全市场岭回归（`alpha ∈ {1e4, 3e4, 1e5, 3e5, 1e6, 3e6}`）；
   - **`G4_BASE_TOP_RANKFT`**（GPU 1）：冻结 `Kronos-base` 底层 `layers 0..8`（共 12 层冻 9 层）与所有嵌入层，仅放开顶层 `layers 9..11 + norm + 线性排序头`，并用同日截面多周期 Cosine-IC（`d3/d5/d10 + orth10`）+ `Base teacher KL + 参数 L2` 双锚微调。

## 2. 判定基准与跨模型融合

在 65 天 OOS（`2026-07-17 .. 2026-10-23`）上同时检验：
1. `G4_BASE_*` 单模型以及与 `C2 (16p)` 的 `50/50` 秩融合；
2. 跨架构三方融合（预注册等权 `1/3 * C2 + 1/3 * G1_UNIV_LAST + 1/3 * G4_BASE_BEST`）是否能在 G1 新高（`Rank IC 0.1694`, `Neutral IC 0.1006`, `k=20 +20.13% / MaxDD -10.70% / Calmar 1.881`）基础上继续降低回撤或抬升 Calmar。
