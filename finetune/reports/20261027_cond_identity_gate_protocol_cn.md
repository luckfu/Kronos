## 1. 口径问题（四条，按杀伤力排序）

### 1.1 `sector_emb` 几何：一条 0 成本的判读（P0-1 已填）

审阅稿 §3.2 的“`sector ‖W‖_F ≈ 5.39 ≈ init`”跨模型不可读：Small 是 **zero-init**（`model/kronos.py:250`），从 0 长到 15.7；Base A+C 是 `Normal(0,0.02)`，init 本身就是 5.381。同一句“≈ init”在两边含义相反。

换成每元素 RMS（`‖W‖_F / √(87·d)`）：

| 模型 | 形状 | init | ‖W‖_F | 每元素 RMS | 相对 init |
|---|---|---|---|---|---|
| Small C2 best | 87×512 | 0（zero） | 15.7 | **0.074** | — |
| Base A+C Seg5 | 87×832 | 0.02 | 5.387 | **0.0201** | 1.00×（未动） |
| Base 裸 Boot Seg155 | 87×832 | 0（zero） | 1.5077 | **0.00560** | — |
| Base 裸 Boot Seg170 | 87×832 | 0（zero） | 1.6212 | **0.00603** | — |
| Base 裸 Boot Seg175 | 87×832 | 0（zero） | 1.6547 | **0.00615（实测）** | — |

数据来源：训练内 Condition Monitor `sector_embedding_weight_norm`（=‖W‖_F），分母 √(87·832)=269.04，**含 unknown 行**（与“排除 unknown 的完整行几何”是两个口径；含 unknown 对 RMS 的偏差约 0.6%，不改变判定）。落盘见 `20261027_p0_cond_identity_results_cn.md`；行范数分布、行间余弦、cos(row,mean)、between-sector 占比**仍缺**，且已无法从 Seg155/170/175 补测（→ §4.1）。

**这一格填上之后，判读发生了两处变化，必须同步改口：**

1. **不是“噪声底”，是“刚起步”。** 相干度 = 0.00615 / 0.548 = **1.1%**（分母为“符号完全一致”的位移上界，见 §4），比纯扩散底（2.3e-3）高 2.6×。说明**机制确实在走**，只是慢——不是“CE 没在驱动”。
2. **离可比状态差 12.0×**（0.074 / 0.00615）。按实测增速外推需 ~2.1k–6.1k 段（§4），仍是周-月级。

因此**旧的“≈0.002（扩散估计）”一行作废**，任何“还在噪声底、所以无信息”的表述不再成立；替代表述是“起步中，差 12×，不足以判”。

### 1.2 `trunk_ratio` 不可移植

分子分母都随注入位点漂移：Small 在 6/8 层、512d；Base 在 10/12 层、832d，residual 范数不同量级。更严重的是**文档没写这个比值是在 γ 之前还是之后测的**——代码里 `condition_trunk_norm_ratio` 在 `_add_context` 内、`x + condition` 之前算（`model/kronos.py:300-318`），而 `condition_scale` 在 kernel 版里挂在哪一侧，master 上查不到。两种读法给出的“淹没倍数”差 20 倍以上。

→ **必须同时报 `condition_output_norm` 与 `trunk_input_norm` 两个绝对值**（stats 里本来就有），比值只作附注；口径写死为“同注入层、γ 之前”。

### 1.3 能量门会被常数偏置蒙过

`20261027_sector_emb_collapse_probe.md` 自证：B 把 `size_mlp` 放大成近常向量（size 128 vs sector 15）。一个全市场同向的市值偏置即可把 `trunk_ratio` 顶过 0.02，而身份为零。**能量门与内容门不是两份独立证据。**

### 1.4 两条读数不同源

- Small PASS 来自离线 kernel（`kronos-small-c2-cond-identity-ablation` + `cond_identity_ablation_result.json`），**代码与 JSON 均不在 master**；
- Base FAIL 来自训练内 ablation（`finetune/train_predictor.py:2068-2112`，teacher-forced、quick 2048，`launch_bootstrap.py:299`）。

“160 倍”里有多少是管线差，现在无法排除。另：`condition_scale` 在 master 上**不存在**（`git log -S condition_scale` 只命中文档），而 hub 加载默认 `strict=False` —— 把 A+C/γ ckpt 丢给 master 代码复评，γ 会被**静默丢弃**（25→1），结果必然错。

## 2. 门定义（替换审阅稿 §2）

能量门从“门”降为**遥测 + 护栏**；判定由 G1/G2 承担，G3 才是论文口径。

| 层 | 指标 | 判据 | 说明 |
|---|---|---|---|
| **G0 遥测/护栏** | `condition_output_norm`、`trunk_input_norm`、比值（γ 前、同层）；注入向量 between-sector 方差占比；`sector_emb` 每元素 RMS | **不设 pass/fail**。护栏：比值 ≤ 0.3（防爆）；between-sector 占比 ≥ 0.3（防恒等偏置顶包） | 只做归因 |
| **G1 CE 身份** | `FS = CE_full − CE_shuf`（K=8 置换均值）；零假设 `null = CE(perm_a) − CE(perm_b)` | `FS ≥ max(3·|null|, 1e-3)` **且** 连续 ≥3 次 eval 同号 **且** 95% CI 下界 > 3·|null| | 允许“可分辨” |
| **G2 输出身份** | 反事实换行业（保市值）→ 预测 10d 收益分位变化率 `r_swap`；换市值（保行业）→ `r_size` | `r_swap ≥ 5%` 且 `r_swap ≥ r_size` | 身份进入预测 |
| **G3 下游可用** | OOS Rank IC / 行业中性化后增量 | 正号且量级可报，单独出表 | 只有这层进论文 |

必报的分解行（G1 下挂）：`FS_sector`（换行业、保市值）与 `FS_size`（换市值、保行业）。现在的 roll-1 同时置换三者，无法归因到“行业身份”。

**为什么用 `perm_a vs perm_b` 作零假设**：1e-5 不是噪声底，它只是 Base 在 γ=1 下的历史巧合值。两个不同置换之差由构造决定其量级，且**自动随该模型自身的条件敏感度缩放**，因此跨架构可比、跨阶段可比。成本是每个 eval 多一次前向。

## 4. 预算算术（为什么“再跑长一点”不是主杠杆）

| | Small C2 best | Base 裸 Boot@Seg175 | 来源 |
|---|---|---|---|
| 累计 segment | 2505 | 175 | 血缘累加 |
| 样本 | 50.1M（4.70 遍） | 3.5M（0.33 遍） | ×20k/seg |
| windows/param | **2.02** | **0.034**（差 59×） | ÷24.82M / ÷102M |
| `sector_emb` 每元素 RMS | 0.074 | **0.00615（实测）** | §1.1 |

位移预算：条件 LR 1e-5 × 313 updates/seg × 175 seg = 5.5 万步。
- **相干上界**（该步数下符号完全一致）= 1e-5 × 5.5e4 = **0.548**/元素；
- **扩散底**（Adam 步长≈lr、符号随机）= 1e-5·√5.5e4 = **2.3e-3**/元素。

实测与上界对照：

| 量 | 值 | 读法 |
|---|---|---|
| 实测 RMS@Seg175 | 0.00615 | 处 [2.3e-3, 0.548] 区间内：比扩散底高 **2.6×**，占相干上界的 **1.1%** |
| 相干度 | **1.1%** | 有系统性分量，不是纯扩散；但只用掉 1/90 的预算 |
| 近期增速 | 155→170：2.81e-5/seg；170→175：2.48e-5/seg | 近似线性，略减速 |
| 拟合指数 p（RMS ∝ T^p） | **0.70–0.77**（20 段窗口，噪声大） | 介于 √T 与线性之间，需在 200/225 段更新 |
| 到 Small 的差距 | **12.0×** | 0.074 / 0.00615 |

外推到 0.074：

| 假设 | 所需段数 | 备注 |
|---|---|---|
| 线性过原点（按 0→175 的均值斜率 3.51e-5/seg） | **~2.1k** | 最乐观读数（把减速当成不存在） |
| 线性、按近期瞬时斜率 2.5e-5/seg | **~2.9k** | 比上一行保守，二者差 40% 来自 155–175 已出现的减速 |
| p=0.77（155–175 两点拟合） | **~4.5k** | 当前数据的中位读数 |
| p=0.70 | **~6.1k** | 若减速继续 |
| 纯扩散（p=0.5） | ~25k | 上界情形，实际不应发生 |

**结论（更新）：机制在走，速度是瓶颈。即便最乐观也要 ~2.1k 段（中心 4.5k 更可信），即当前 175 段的 12–26 倍；对双 T4 是周–月级。**但“抬 γ / 条件 LR 加速”不是默认动作：它只在 §4.2 判“Base 显著低于 Small 曲线”时才有依据；若 Base 落在曲线上，加速只是把 12× 压缩成 3×，仍不可比。

配套：脚本注释的 `~29 min/seg`（`launch_bootstrap.py:39`）与“10-26 开训、10-27 已到 Seg175”对不上，预算测算必须换成实测墙钟（P0-4）。

### 4.1 硬规则：判门 ckpt 必须不可覆写（2026-10-27 事故后新增）

**事故**：Bootstrap 走 self-parent 接力、且 `KRONOS_DISABLE_BEST_UPDATES=1`，只留 `last_model`；Seg155/170/175 的权重被后续 chunk 覆盖。后果：

1. 这三行**永远只剩** Monitor 上报的 ‖W‖_F，行范数 / 行间余弦 / between-sector **补不出来**；
2. P0-2 无法“同段重评”，Seg175 只能退役改锚（§3）；
3. 审阅稿 §3.3 那条“至 Seg175 仍无内容”的读法，从此**不可复核**。

**规则**（自下一 chunk 起）：

- 任何要进判门表的评估，必须绑定**不可覆写快照**：`ckpt_sha256` + 归档路径 + 保留期；
- 快照时机：chunk 结束前、eval 之后（保证 sha 与 eval 的 `lr_at_eval` / `segment` 一一对应）；
- **无快照的行作废**，不得进 §7 结论页，也不得在正文当证据；
- 判门表新增一列 `ckpt_snapshot`（路径），空 = 作废。

> 这条比 P0-3 便宜得多，但不做的话每一次判门结论都会在 24 小时内变成不可复核的历史读数——本轮已经发生过一次。

### 4.2 复刻的正确判据：Δ 对齐 + FS–Δ 曲线 + 分辨率（2026-10-27 收敛）

**为什么段号/预算不能当判据**：FS 是“走到哪”的函数，不是“配方是什么”的函数。Small 在 2505 段走到 Δ=0.0744，Base 在 175 段走到 0.00615；段号差 16×、Δ 差 12×，两个数绑死在一起——任何“同段比较”都必然把“没走够”读成“学不出”。

保留三样，其余全砍：

#### ① Δ 对齐（判据）

判门只在**同一 Δ** 下比 FS。`Δ = ‖W‖_F/√(87·d)`（zero-init 模型即位移）。每个点报：`(Δ, FS, n, sd(Δ), lr_at_eval, ckpt_sha256)`。

- 不做段号对齐；
- 配置只决定 Δ 的**生长速度**，不决定 `FS–Δ` 关系——“配方对齐”不等于“状态对齐”。

#### ② FS–Δ 曲线（参照系，Small 侧先量）

在 Small 侧取 ≥3 个不同 Δ 的 ckpt（血缘里已有 C2 / C03 / epoch2 / e03b 等），测出 Small 自己的 `FS(Δ)`：**同样的位移，Small 换来多少身份效应**。这就是把“差 12 倍”变成“在不在同一条曲线上”。

- 每个点同 harness、同 `K=8`、同 null、同 `n`（按 §3 定）；
- Δ 覆盖目标：跨 0.005 → 0.08 一个数量级。

#### ③ 分辨率（可判性）

`SE(FS) = sd(逐窗ΔCE)/√n`，**先量 sd 再定 n**，目标 `SE ≤ 1/3 × 待判间距`。

- n=2048、sd≈1e-2 → SE≈2.2e-4，**比 H_slow 的预测（1.8e-4）还大**，判不了；
- 同条件下需 n≈30k；评测只是前向，30k 窗远便宜于训练。

#### 判读规则（运行前写进结果表）

| Base 的点相对 Small 曲线 | 结论 | 下一步 |
|---|---|---|
| 落在曲线上（±1 SE） | 复刻成立，只是没走够 | 继续走；**此时**抬 Δ 生长速度（γ / 条件 LR）才有依据 |
| 显著低于曲线（>3 SE） | 单位位移的身份效应被稀释（淹没） | 启用 P0-3，定位是注入位点 / 损失 / 优化 |
| 显著高于曲线 | 与预期相反，先查管线与 Δ 口径 | 不下结论，重测 |
| Δ 区间不重叠（Small 无低 Δ 点） | 单点比较 | 记“不可判”；按预算决定是否补段（§4 外推 2–4.5k） |

**横轴口径（重要）**：Δ 轴只在 **γ=1（bare-add）** 时成立。若启用 γ，横轴必须换成**有效注入** `γ·row_norm/trunk_norm`，否则两张点不在同一坐标系，曲线不可比。

**降级规则**：若 Small 侧拿不到低 Δ 的 ckpt，曲线退化为单点 → 判据变成“Base 走到 Δ≈0.074 再比”。

| **P0-3** | 冻结 trunk 条件专训探针（§6）**——条件性启用** | 1–2 小时级 | `FS*(γ, lr)` | **仅当 P0-5 判“Base 显著低于曲线”才做**；否则不做 |
| **P0-4** | 实测单 seg 墙钟、updates/seg、val+ablation 占比 | ~0 | 预算表 | 反推本轮可承载段数 |

P0-2 的落盘要求：`fs_mean`、`fs_sd`（跨置换）、`null`、`fs_sector`、`fs_size`、`per_window_delta_sd`、`ci95`、`n`、`windows_index_sha256`、`lr_at_eval`、`segment`、`ckpt_sha256`。

## 6. 冻结 trunk 探针（P0-3 设计，**条件性**）

> **触发条件**：仅在 §4.2 判为“Base 显著低于 Small 曲线”时启用。若 Base 落在曲线上，本节的 `FS*` 无用（问题已由曲线回答），跳过。

目的：在**不动主干**的前提下，给出“这套注入位点 + 这套 CE 最多能长出多少身份”的**上界** `FS*(γ, lr)`。这是唯一能在小时级回答“淹没 vs 饿着”的实验。

- 可训练：`sector_emb` / `size_mlp`（+γ 若启用），~78K 参数；trunk 全冻。
- 网格：γ ∈ {10, 30, 100} × 条件 LR ∈ {1e-4, 3e-4, 1e-3, 3e-3}（78K 参数、无主干干扰，可用远高于 1e-5 的 LR）。
- 步数 200–600，batch 64，取训练段；每个 cell 在 2000 窗上打 K=8 + null + 2×2。
- 落盘：`FS*`、`sector RMS`、between-sector 占比、`r_swap`。

判定：

| 观测 | 解释 | 动作 |
|---|---|---|
| max `FS*` < 1e-3 | 该注入位点/该损失**表达不出**身份 | 停长叉；问题改为“要不要 identity-sensitive 项 / 换注入位点” |
| `FS*` 随 γ 升后塌 | 淹没确认（结构性） | 取拐点 γ，长叉按拐点设 |
| `FS*` 在**高 LR 侧**才起来，且 ≥5e-3 | 主因是**条件 LR**，不是段数 | 长叉降级为“条件 LR 调参”，先跑 50–100 段验证 |
| `FS*` 与 γ、lr 都弱 | 上界本就低（信息论上限） | 2e-3 已是天花板，放弃“抬到 1e-2”的期待 |

## 7. 长叉开启条件与中期停看

**配方（2026-10-27 已改）**：**真复刻 = bare-add + zero-init + 同数据 / 同 loss / 同 LR**。**A/C 两条修复（γ、非零 init）已从默认方案移除**——零初始化已被 Small 自己证否为“不足”：Small 用同一个 `nn.init.zeros_`（`model/kronos.py:250`）从 0 长到 15.7；加法路径零初始化不阻断梯度（`∂L/∂s = ∂L/∂x`）。γ 只在 §4.2 判“曲线下方”时作为**独立对照臂**加入，且加入后横轴按 §4.2 换成有效注入。

**三条前置（全中才开）**：① P0-2 + P0-5 完成，Base 的点已落在 Small 曲线上，或 Δ 不重叠时已决定补段；② 若判“下方”，P0-3 已给出可救的注入 / LR 证据；③ 预算覆盖**退火尾**（`uniform_cosine` 到 ~1e-6 的收口段）。

| 检查点 | 主看 | 停/走 |
|---|---|---|
| 12.5% | sector RMS 斜率；`FS` vs `null` | 斜率≈0 且 `FS < null` → **停** |
| 25% | 同上 + 有效注入比（G0 护栏；γ=1 时即 trunk_ratio） | 比值 >0.3 → 降 γ 或停 |
| 50% | sector RMS 斜率是否 ≥ 首 1/4 的 20% | 否则 **停**，只记“该配方在此预算内未起”；不得外推为机制结论 |
| 75% | 退火中段 G1 趋势（≥3 次同号） | 趋势不单调 → 记“未收敛”，不加段 |
| 100%（LR≤2e-6） | G1 + G2 | 终判；G1 过而 G2 不过 → 记为“CE 可分、预测不可用” |

必落盘的 5 个数：sector RMS、between-sector 占比、`FS`(K=8,mean±sd)、`null`、`r_swap`；每条都带 `lr_at_eval`。

## 8. margin 政策

- **先无 margin**：无 margin 是科学问题（CE 能否自行长出身份），margin 是工程手段（强行造出身份）。
- margin 直接优化 `CE_full − CE_shuf + m`，因此**必然把 G1 顶过去**——用 G1 判 margin 的成功是循环论证。margin 版只认 G3。
- `m` 必须锚在 `FS*` 上（建议 `m = 0.1–0.3 × FS*`）。P0-3 之前定 m 都是拍脑袋。
- margin 版单独开叉、单独命名，不并入 live Bootstrap，不与无 margin 版共用看板。
