# GPU 探索 G22 事前登记：零微调 `Kronos-small` 极短微周期扫描 `[L16, L24, L32, L40]`（`wynstonliu` 剩余额度清零快筛）（2026-11-18）

- 创建时间：2026-11-18
- 硬性纪律：严禁触碰 `2026-10-24+` 封存验收窗；超参选择严格在未见面验证集 `2026-05-18 .. 2026-07-02`，最终重拟严格截止 `2026-07-02`；OOS 窗口 `2026-07-17 .. 2026-10-23`（65 天 / `335,312` 行）。

## 1. 立项依据

1. 精准利用 `wynstonliu` 本周剩余 `0.60h（36 分钟）` GPU 额度，补全 G16/G21 之外更细粒度的 **微周期下探 `[L16, L24, L32, L40]`**（`2021-01..2026-07 stride=3`，`194.4 万` 行，预计耗时 `~16–22 分钟`）；
2. 将正则网格推至 `1e8`，绘制 512 维零微调小模型从 `16 日` 到 `120 日` 的完整单窗频率响应曲线，检验极短反转周期（`L=16 / 24 / 32`）与 `L=40 / 45` 是否互补。

## 2. 预注册候选

- `g22_pts_l16` / `g22_pts_l24` / `g22_pts_l32` / `g22_pts_l40`（各 `512d`）
- `g22_pts_micro_raw` / `g22_pts_micro_multi` / `g22_pts_micro_orth`（`2,048d` 四微窗融合）
