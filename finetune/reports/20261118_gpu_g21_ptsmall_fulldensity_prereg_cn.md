# GPU 探索 G21 事前登记：零微调 `Kronos-small` 8 年全密度（`2018-2026 stride=1` ~`828 万` 样本）超短窗与跨深度（2026-11-18）

- 创建时间：2026-11-18
- 硬性纪律：严禁触碰 `2026-10-24+` 封存验收窗；超参选择严格在未见面验证集 `2026-05-18 .. 2026-07-02`，最终重拟严格截止 `2026-07-02`；OOS 窗口 `2026-07-17 .. 2026-10-23`（65 天 / `335,312` 行）。

## 1. 立项依据

1. `G16` 发现未经微调的 `NeoQuasar/Kronos-small` 在 `L=45` 下即凭 512 维单头拿下 `0.1688（中性化 IC 0.1185 / FUSE 0.1943*）`，且与微调版 `C2` 相关性仅 `0.2364`、并触及网格上限 `alpha=3e6`；
2. 借助 `24.7M` 极快的前向速度，本实验首次在全系列跑通 **完整 2018-2026 全密度 `stride=1`（约 `828 万` 行）**，提取 `[L20_L6, L30_L6, L45_L3, L45_L5, L45_L6]`（`2,560d`）并将正则网格延展至 `1e8`，可直接产出现有生产架构（512d）或双端高精单Pass的新强候选。

## 2. 预注册候选

- 单窗 `512d`：`g21_pts_l20` / `g21_pts_l30` / `g21_pts_l45_full8y`
- `L=45` 跨深度 `1,536d`：`g21_pts_l45_ml_raw` / `g21_pts_l45_ml_multi`
- 全频段 `2,560d`：`g21_pts_band_raw` / `g21_pts_band_multi` / `g21_pts_band_orth`
