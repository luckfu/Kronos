# GPU 探索 G2 Pre-registration：端到端冻结底层 + 顶层 Transformer 截面排序与变长回看微调（2026-11-15）

**状态**：事前登记（早于 G2 GPU Kernel 推送及任何 OOS 计算）。  
**研究纪律**：严格不触碰 `2026-10-24+` 封存验收窗口；所有训练仅用 `train_data.pkl <= 2026-04-30`；早停与候选选择仅看 `val_data.pkl 2026-05-18..2026-07-02`（未见过股票 + 隔离期后）；OOS `2026-07-17..2026-10-23`（335,312 行）仅作一次性评估。

---

## 1. 核心假设（为什么 G2 能突破冻结线性头天花板）

先前实验发现了一条关键瓶颈：
- 冻结 `C2` 特征上的线性头（`RIDGE_BASE`）虽只有 `0.0958` 单模型 IC，却贡献了 `0.0740` 因子中性化 IC 且与 `C2 AR` 相关性仅 `+0.17`，使 `FUSE_RIDGE_C2` 将 `k=20` 收益从 `+11.47%` 提到 **`+15.49%`**、Calmar 从 `0.564` 翻倍至 **`1.194`**。
- 但 `C2` 全部 8 层 Transformer 从未收到过来自**同日横截面收益排序**的梯度，而先前 `c2_rolling_retrain` / `base_clean` 用 CE 微调全网则拖偏整体多空均值、摧毁排序信号。

本实验在 **2× Tesla T4** 上直接改造微调范式，从四点根本修正失败原因：
1. **选择性冻结**：冻结 Tokenizer、Token/Time/Sector/Size 嵌入层与底层 Transformer（`layers 0..4`），**仅放开顶层 `layers 5..7 + norm` 与线性排序头 `LayerNorm + Linear(1024, 1)`**（将 `[h_last, h_m5]` 拼成 `1024` 维输入，绝不加易过拟合的非线性 MLP 瓶颈）。
2. **多周期同日截面 Cosine-IC 损失（与大盘涨跌完全无关）**：
   - 每个优化步采样**同一交易日截面** `B=256` 只股票，目标为跨期平滑秩 `0.15*d3 + 0.25*d5 + 0.60*d10` 叠加 `0.30` 权重的**剥离市值/行业/反转正交残差秩**。
3. **双锚防遗忘正则（KL + 权重 L2）**：
   - 借助共享冻结底层 `h4` 的冻结 `C2` 顶层快照，约束 `0.05 * KL(p_s1^C2 || p_s1^FT) + 1e-3 * ||theta - theta_C2||^2`，防止表征塌缩或丢失原本的 K 线流形。
4. **验证变长回看窗口训练假设（直接回应用户关于可变输入长度调教的设想）**：
   - **Arm A (`G2_FT_L120`)**：固定 `lookback=120` 训练与评估；
   - **Arm B (`G2_FT_VARLEN`)**：每个日度截面 batch 随机采样 `lookback ∈ {60, 90, 120}` 训练，验证与评估均采用 `L=60` 与 `L=120` 截面 z-score 等权双视角集成。

## 2. 训练细节与选型标准

- 数据：`train_data.pkl`（`2020-01-01 .. 2026-04-30`，全部有效截面日），`val_data.pkl`（`2026-05-18 .. 2026-07-02` 选最佳 epoch）。
- 优化器：`AdamW(lr_top=2e-5, lr_head=2e-4, weight_decay=1e-2)`，cosine 退火，每个 Arm 跑 `4 epochs`（约 5,000+ 同日截面步）。
- **验证集选模准则**：每半个 epoch 在 `val (2026-05-18..2026-07-02)` 计算 `score = 0.5 * Val_Rank_IC + 0.5 * Val_Orth_IC`，保存最佳权重与 OOS 预测分数。

---

## 3. OOS 评估与判定标准

在 65 天 OOS（`2026-07-17 .. 2026-10-23`）上同时评估：
1. `G2_FT_L120` 与 `G2_FT_VARLEN` 各自**单模型**；
2. 各自与 `C2 (16p)` 的预注册 `50/50` 秩融合（`FUSE_G2_L120`, `FUSE_G2_VARLEN`）；
3. 若在 `val` 上明显优于 G1/基线，进一步在后续 G3 检验其微调后权重做 **16 路径 AR 采样**是否也能超越原版 `C2 AR`。

**晋级门槛**：超越当前冠军 `FUSE_RIDGE_C2`（`Rank IC 0.1503`, `Neutral IC 0.0985`, `k=20 +15.49% / Calmar 1.194`）。
