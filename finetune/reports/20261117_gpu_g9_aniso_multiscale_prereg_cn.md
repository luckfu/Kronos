# GPU 探索 G9 事前登记：各向异性分块正则化跨架构多尺度回归（`Small 512d + Base L60/L120 2496d`）

- 创建时间：2026-11-17
- 硬性纪律：严禁触碰 `2026-10-24+` 封存验收窗；超参选择严格在未见面验证集 `2026-05-18 .. 2026-07-02`，最终全训练期重拟严格截止 `2026-07-02`；OOS 评估严格在 `2026-07-17 .. 2026-10-23`（65 天 / `335,312` 行）。

## 1. 立项依据（基于 G1 / G4 / G5 / G7 已观察结果）

1. **为什么 G7 跨架构联合回归（单 `alpha * I`）未打败“分头融合”**：
   - G1（`Small 512d`, `2021-2026`）最优正则为 `alpha = 1e4`（G5 `2018-2026` 为 `1e3`）；
   - G4（`Kronos-base 1,664d`, 无微调）最优正则高出一个量级：`alpha = 1e5`；
   - G7 将两者拼为 `2,176d` 后用同一个 `alpha * I` 约束，导致 `Small` 与 `Base` 无法同时处于各自最优正则强度下。
2. **尚未提取的 `Kronos-base` 短窗信息（`L=60`）**：
   - G1 中 `Small L=60` 与 `C2` 秩相关仅 `0.2746`；G4/G7 至今尚未提取 `Kronos-base` 在短窗 `L=60` 的隐状态（`832d`）。
3. **流式二阶统计量求解**：
   - 按日期在 2× T4 上流式累加 `3008 × 3008` 矩阵 `G = X^T X` 与右端向量 `b = X^T y`，CPU/GPU 内存恒定 `< 150 MB`；网格搜索 `3 × 3 = 9` 组 `(alpha_small, alpha_base)` 只需数秒矩阵求逆。

## 2. 实验设计与预注册候选

- 训练范围：`2021-01-01 .. 2026-07-02`（`stride=2`，流式截面标准化 `clip=5.0`），兼顾 G1 的近期结构锋利度与足量样本；
- 特征向量 `3,008d`：
  1. `C2_L120_last`（`512d`）
  2. `Base_L120_last`（`832d`）
  3. `Base_L120_m5`（`832d`）
  4. `Base_L60_last`（`832d`，对最近 60 根 K 线独立分词前向）
- 预注册候选头（全在 `2026-05-18..2026-07-02` 选参）：
  1. `g9_base_l60_832`：纯 `Base_L60_last`（`832d`, `alpha in {1e4..1e6}`）
  2. `g9_base_ms_2496`：纯 `Kronos-base` 三尺度（`2,496d`, `alpha in {1e4..1e6}`）
  3. `g9_aniso_raw`：各向异性分块正则 `diag(a_s I_512, a_b I_2496)`，`a_s in {3e3, 1e4, 3e4} × a_b in {3e4, 1e5, 3e5}`，拟合 `y_raw10`
  4. `g9_aniso_orth`：同上网格，拟合市值/行业/10日反转正交化目标 `y_orth`（以 `val_ic_orth` 选参）
  5. `g9_aniso_multi`：同上网格，拟合 G5 验证期表现突出的多期限复合收益目标 `y_multi`
  6. `g9_aniso_mix`：`0.5 * z(g9_aniso_raw) + 0.5 * z(g9_aniso_orth)`
