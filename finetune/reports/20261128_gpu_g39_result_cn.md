## 1. 一句话结论与核心突破（精准治愈 `G37` 后半段衰减）

1. **正面治愈上一代蒸馏（`G37`）的 `Seg B` 衰减，实现 `C2-Only` 与 `C2 + 4.1M Mini` 双线反超**：
   - 上一代 `G37` 仅蒸馏 `ret5 / multi` 普通教师，导致 `Seg A / B` 呈现明显下滑（如 `G37_C2ONLY_DISTILL_XSTOCK: 0.198 → 0.145`，`G37_MINIC2_DISTILL_XSTOCK: 0.205 → 0.143`）；
   - **`G39`** 改用“**`CVaR10 + Fwd5-10`（后 5 日延续）+ `Floor10`（抗崩溃底）**”三目标 2-fold OOF 四家族超级教师与非对称尾部损失跨架构蒸馏进不含 `L=120` 与 `G32` 的紧凑学生空间（`STUDENT_DIM = 7188`）后：
     - **纯 `C2-Only`（零任何新底座权重，零 `Mini`）**：**`G39_C2ONLY_MLP_CONT_SHIELD`** 单头飙至 **`Rank IC 0.1944 (ICIR 1.60), NIC 0.1379, Seg A/B = 0.199 / 0.185`**（较 `G37` 同类 `0.1791 / 0.145` 后半段大涨 **`+0.040`**！）；**`FUSE_G39_C2ONLY_RIDGE_FWD5_10`** 轰出 **`IC 0.2154 (ICIR 2.25!!), 100.0% 正天数, Seg A/B = 0.224 / 0.202, k=10 +20.64%, k=20 +19.18%`**；
     - **极简 `C2 + 4.1M Mini`**：**`G39_MINIC2_RIDGE_FWD5_10`** 拿下 **`IC 0.2134, NIC 0.1524`**（与 `C2` 融合达 **`IC 0.2188 (2.16), Seg A/B = 0.229 / 0.203, k=10 +23.16%`**）；**`G39_MINIC2_MLP_FWD`** 单头 **`IC 0.2105`**（融合后 `0.2106, Seg A/B = 0.213 / 0.208, k=10 +22.10%`）；**`G39_MINIC2_MLP_CONT_SHIELD`** 融合后 `Seg A/B = 0.204 / 0.208`（后半段反超前半段，**`k=10 +22.61%`**, `liq10 +3.26%`）；**`G39_MINIC2_LGBM_FWD5_10`** 单头稳守 **`IC 0.2006` 且 `k=10 / k=20` 最大回撤双双压破 `-9.1%`（`-9.10% / -9.09%, Calmar 1.414 / 1.411`）**。
2. **`VAL_SEL` 与 `C2` 正交度全面过关**：
   - 验证期上学生全面兑现（`g39_c2only_lgbm_cvar val_ic=0.1220`, `stu_c2_crashentry=0.1226`, `g39_c2only_xstock=0.1108`, `g39_minic2_dual_mlp=0.1097`）；
   - 所有 16 路学生预测与生产 `C2` 秩相关稳定在 **`0.262 .. 0.368`** 低相关正交带（其中 `fwd5_10` 线性延续头相关性仅 `0.262 / 0.276`）。
3. **客观对比边界（`G39` vs `G37/G40`）**：
   - 以 `cvar10` 纯下尾锚单头直出时，其偏向极低波动防御、与 `C2` 融合后爆发（如 `FUSE_G39_C2ONLY_RIDGE_CVAR k=10 +17.91%` vs 单头 `+8.37%`）；而极高流动性头部（`liq10`）仍以 `G40_FTMINI_RIDGE (+4.49%)` 与 `G37` 更锋利，两者刚好在 **Track D 防跌续航 vs Track B 锐利高流动** 形成完美互补。
