# TimesFM3：原始底座 vs 微调版（SweetSpot）—— 训练前后的差异（2026-11-13）

事前登记：[`20261113_timesfm3_base_vs_finetuned_prereg_cn.md`](20261113_timesfm3_base_vs_finetuned_prereg_cn.md)（跑数之前写定）。
机器可读结果：[`20261113_timesfm3_base_vs_finetuned.json`](20261113_timesfm3_base_vs_finetuned.json)。
脚本：`finetune/timesfm3_v11_trajectory/eval_oos/` 下的 `eval_base_channel.py`（kernel 内推理）、
`push_eval_base_model.py`、`analyze_base_vs_finetuned.py`（本机配对分析）。
评测 kernel：`smmt315/tfm3-base-channel-eval`，双 T4，335,312 条，推理约 39 分钟。

## 1. 一句话结论

**微调主要修好了“校准”，没有证实提升“排序”。**

- 底座系统性看多：平均预测 +4.9% 到 +11.6%，预测上涨的比例 75% 到 88%。微调后接近无偏。
- 平均绝对误差三段全部下降（9.34%→8.41%、12.63%→9.87%、9.72%→8.46%）。
- 排序 IC 的点估计都有提升，但**四段的配对差异区间全部跨 0**，按事前标准判为“无法区分”。
- 7 月上涨那段，底座反而更强（IC 0.289 vs 0.235）。

## 2. 对照口径（B1）

| 项 | 值 |
|---|---|
| 权重 | Hugging Face 公开底座 `google/timesfm-3.0-pytorch`，零 LoRA |
| 输入 | 与微调版完全相同的 7 个数值通道（收盘价、开高低、量、额、市值分位） |
| 行业通道 | **整行置零**（`nn.Embedding` 权重初始化为 0，不训练） |
| 窗口/归一化/推理 | 与 SweetSpot 那次同一份代码 |
| 对齐 | 335,312 条、逐行同序、标签逐位一致（分析脚本内强制校验） |

底座没有行业嵌入，所以把第 8 个通道置零，让两次运行的差别只剩“有没有微调”。
只做了 B1；B2（纯收盘价的原生用法）没有测。

## 4. 微调到底改变了什么

**（1）校准：明确改善，三段一致。**

底座有严重的整体看多偏差，而且随行情放大：A 段预测平均 +4.9%（实际 +0.7%），
C 段 +11.6%（实际 +7.8%），B 段仍 +4.8%（实际 −5.1%）。
微调之后 A、B 两段基本无偏（−0.45%、−0.90%），C 段 +6.5% 也接近实际 +7.8%。
平均绝对误差在三段都比底座低 0.9 到 2.8 个百分点。

**（2）头部的幅度：改善明显，但两边都还是高估的。**

第 10 日，当天排名前 10 的股票：

| 段 | 微调版：预测 / 实际 / 相对大盘 / 达到预测 | 底座：预测 / 实际 / 相对大盘 / 达到预测 |
|---|---|---:|
| A | +20.7% / +3.5% / +2.8% / 10% | **+44.6%** / −0.9% / −1.6% / **0%** |
| B | +20.3% / −10.5% / −5.4% / 2% | **+50.2%** / −13.0% / −7.9% / **0%** |
| C | +29.9% / +16.9% / +9.1% / 25% | **+67.5%** / +18.1% / +10.3% / **1%** |

底座的头部预测是 +45% 到 +68%，几乎没有任何一只股票达到；微调把它压到 +20% 到 +30%，
仍然是高估，但幅度小了一半以上。“预测值按排名系统性高估”这个问题，微调减轻了，没有解决。

**（3）排序：点估计提升，统计上不成立。**

三段 IC 里两段是微调更高（+0.041、+0.044），一段是底座更高（−0.055）。
四段的配对区间全部跨 0。唯一能算“确认”的是：
**B 段微调版的 IC 区间 [+0.018, +0.112] 不含 0，而底座 [−0.008, +0.063] 含 0** ——
也就是说在新窗口上，微调版确实有排序能力，底座不能确认有；但两者之间的差没有达到显著。
换成秩相关看是同一个图景：B 段日均 Rank IC 底座 0.012、微调 0.067；A 段 0.087 对 0.124；C 段 0.394 对 0.307。

## 5. 这对“要不要继续训”的含义

1. **微调是有意义的，但意义在“能用”而不是“更准”。** 底座那种整体看多 5–12 个百分点、
   预测上涨 75–88% 的输出，无论怎么用都会误导；微调把它拉回到接近无偏。
2. **微调没有带来可辨识的选股能力提升。** 若目标是让排序更准，这条训练线的收益已经接近零：
   21 小时（S01 12h + S02 9h）续训换来的是 OOS 下降，而最早那一段微调带来的是校准改善。
3. **基座本身有时序先验。** 底座 IC 0.057（A）、0.025（B）、0.289（C）——它并不是纯噪声，
   在单边上涨的 7 月甚至明显强于微调版。这说明它的信息可能集中在“趋势延续”，
   遇到震荡或下跌就失效，与我们前面在其他模型上看到的一样依赖行情。
4. **口径提醒**：底座的 8 通道是我们按微调版约定拼的（行业通道置零），不是它的原生用法。
   若它的 variate attention 对全零通道敏感，B1 的数字会被低估；要区分只能再跑 B2。

## 6. 局限

1. B 段只有 20 天，且单边下跌；C 段 11 天单边上涨。配对区间宽是样本量的必然结果。
2. 只测了 B1。B2（纯收盘价）没有测，所以不能回答“6 个协变量通道带来了多少”。
3. 底座权重在 kernel 内从 Hugging Face 下载（公开仓库，无需凭据），本轮一次成功；
   如果上游改动，需重跑。
4. 两边都只用第 10 日；1–9 日的逐日结果在 kernel 的报告里，本轮没有展开。
