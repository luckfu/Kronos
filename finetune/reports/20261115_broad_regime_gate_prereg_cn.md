# 宽基/等权大盘风控门控对比：事前登记（2026-11-15）

> 在运行本轮 65 天 OOS 回测之前写定。全程不触碰 `2026-10-24+` 封存验收窗；阈值仅在训练前窗口 `2026-02-02 .. 2026-07-02` 上核验分布，不在 OOS 上调参。

## 1. 研究动机与问题

在上一轮 [`20261115_nonpv_and_regime_result_cn.md`](20261115_nonpv_and_regime_result_cn.md) 中已确认：
1. `C2 (16 路径 T=0.65, p=0.80)` 在 65 天 OOS（`2026-07-17 .. 2026-10-23`）上，`k=20`（每 10 个交易日轮动、30% 缓冲）取得 `+11.47%` 扣费净收益（10/10 起始日跑赢全市场），`k=10` 取得 `+11.88%`，但最大回撤高达 `−20.33%` / `−22.09%`。
2. 门控 `G_CSI300 = int(CSI300 > MA20) + int(全市场高于MA20比例 >= 0.35)` 把最大回撤压缩约 60%（至 `−8.37%` / `−8.87%`），但全期平均仓位仅 `33.4%`，净收益降为 `+4.06%` / `+4.39%`。诊断发现 `CSI300 > MA20` 在 65 天中仅满足 `8/65` 天（沪深 300 权重偏大盘，滞后于 `C2` 所选的中小盘全市场截面），而全市场宽度 `>= 0.35` 满足 `38/65` 天。

## 2. 检验假设

**H_REGIME2**：用与全市场横截面选股更同频的因果趋势指标（中证 1000 `CSI1000`、全市场等权净值曲线 `EW_INDEX` 或纯宽度三档门控）替代偏大盘的 `CSI300` 趋势项，在保持显著回撤保护（相对裸持 `C2` 最大回撤明显收窄）的前提下，能显著减少夏季踏空、提升风险调整后净收益（Calmar 与超额收益）。

## 3. 固定门控规则（阈值仅按 `2026-02-02 .. 2026-07-02` 98 天预校验确定）

在调仓信号日 `T` 收盘后、仅使用 `<= T` 的日线数据计算三档仓位目标（`0 → 空仓`、`1 → 半仓 k//2`、`2 → 满仓 k`，复用 `nonpv_and_regime_study.run_gated_slots`）：
1. **`RAW`**（基线）：始终 `2`（满仓）。
2. **`G_CSI300`**（旧门控对照）：`int(CSI300[T] > CSI300_MA20[T]) + int(breadth_ma20[T] >= 0.35)`。
3. **`G_CSI1000`**：`int(CSI1000[T] > CSI1000_MA20[T]) + int(breadth_ma20[T] >= 0.35)`（OOS 前 98 天 `>MA20` 占比 56.1%，三档 `{0:40, 1:20, 2:38}` 左右）。
4. **`G_EW`**：`int(EW_INDEX[T] > EW_MA20[T]) + int(breadth_ma20[T] >= 0.35)`，其中 `EW_INDEX` 为 `volume > 0` 个股当日收盘等权日收益累乘净值曲线（OOS 前 98 天 `>MA20` 占比 45.9%，零外部指数偏差）。
5. **`G_BREADTH`**（纯宽度三档）：按 OOS 前 98 天宽度分布约 40%/60% 分位固定阈值（`0.30` 与 `0.45`）：`<0.30 → 0`、`[0.30, 0.45) → 1`、`>=0.45 → 2`。

## 4. 评测口径与输出指标

- 统一使用 `C2 (16 路径 T=0.65, p=0.80)` 分片（`scratch/non_pv/c2_p16_65d/`），信号日 `2026-07-17 .. 2026-10-23`（65 天）。
- 回测规格：`k=10` 与 `k=20`，`step=10`，10 个错位起始日，`30%` 缓冲卖出，流动池 `20 日成交额中位数 >= 5000 万`，次日开盘成交，扣双边滑点 + 0.15% 手续费。
- 报告指标：10 起始日平均扣费净收益、相对全市场平均净超额及范围、跑赢全市场起始日数、平均最大回撤、**Calmar 比（`mean_net / |mean_max_drawdown|`）**、平均仓位、每次下单数、相对全市场与相对 `RAW` 的日度净差 10 日块 bootstrap 95% 区间（seed `20261115`, 2000 次）。
