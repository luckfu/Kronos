# GPU 探索 G10 事前登记：冻结 `G1_UNIV_LAST` 线性骨架的同日板块/全市场残差同行注意力网络（2026-11-17）

- 创建时间：2026-11-17
- 硬性纪律：严禁触碰 `2026-10-24+` 封存验收窗；严格在未见面验证集 `2026-05-18 .. 2026-07-02` 选参，最终重拟截止 `2026-07-02`；OOS 评估窗口 `2026-07-17 .. 2026-10-23`（65 天 / `335,312` 行）。

## 1. 立项依据

1. 在 G3 中，`CrossStockPeerRanker` 在 `k=10` 与 `k=20` 上均跑赢了自身的线性 skip 基线（`+16.58% vs +14.94%`、`+14.74% vs +13.08%`），证明“同交易日 86 板块原型 + 全局市场总结 token 的同行注意力残差”确实携带线性回归无法表达的截面相对估值信息；
2. 但 G3 存在两个可控缺陷使其未胜过 `FUSE_G1_UNIV_LAST`：
   - G3 用 `alpha = 1e5` + `0.7*multi + 0.3*orth` 拟合 `skip`（正则过强、偏离了 G1 最优的 `alpha = 1e4` 原始目标解）；
   - G3 训期间同时解冻更新 `skip`，导致多轮梯度更新漂移了闭式岭回归全局最优解。
3. **G10 精准修复**：
   - 将训练区间定在近期一致生态 `2022-01-01 .. 2026-07-02`（`stride=2`，流式提取并仅保存 compact `float16` 512d 截面）；
   - **`skip` 严格固定为闭式全市场 `G1_UNIV_LAST`（`alpha = 1e4`, `y_raw10`）且全程冻结（`requires_grad=False`）**；
   - 仅训练极轻量零初始化残差同行注意力分支 `beta * ctx_head(z - own_sec, attn_out, z * mkt_tok)`，并在验证集 `2026-05-18..2026-07-02` 选择残差缩放与正则强度 `(scale, weight_decay, epochs)`。

## 2. 预注册候选

- `g10_linear_g1ref`：纯冻结 `2022-2026 stride=2` `alpha=1e4` 线性骨架（对照基准）
- `g10_peer_raw`：纯冻结 `skip` + 同行注意力残差（目标 `y_raw10`，验证 `val_ic_raw` 选超参）
- `g10_peer_mix`：纯冻结 `skip` + 同行注意力残差（目标 `0.7*y_raw10 + 0.3*y_orth`，验证综合 `0.5*val_ic_raw + 0.5*val_ic_orth` 选超参）
- `g10_peer_blend`：`g10_peer_raw` 与 `g10_peer_mix` 截面标准化等权融合
