# C2 隐状态非线性截面排序头（MLP Cosine-IC）：事前登记（2026-11-15）

> 全部训练、早停与超参选择严格限制在 `2025-07-03 .. 2026-07-02`（`val_hidden_*.npz`，516 只验证股），不接触 `2026-07-17 .. 2026-10-23` 与 `2026-10-24+`。若本轮候选在 65 天窗口显著胜出，后续仍需在完全未触碰的 `2026-10-24+` 窗口独立验收。

## 1. 为什么在 T3（线性 Ridge）之外重测隐状态模型

在 [`20261112_head_c2_fusion_result_cn.md`](20261112_head_c2_fusion_result_cn.md) 中：
- 线性预测头（`512 → 1`，`Ridge alpha=1e5`）与 `C2` 排序相关性仅 `0.15`，9 月表现强（`0.171` 对 `0.092`），但在 7–8 月 A 段只有 `0.064`，导致与 `C2` 融合在 A 段略逊于 `C2`（`0.135` 对 `0.152`）。
- 已知瓶颈有两个：
  1. `T3` 用全局池化样本的**线性 MSE** 拟合 `pct_rank(ret10)`，无法表达 Transformer 最后一层隐状态 `h` 里的非线性截面交互（而 `C2` 自身 DualHead 是非线性自回归分布采样）。
  2. 没有直接以**每日横截面排序相关性（Cosine-IC / Listwise 目标）**作为优化目标。

## 2. 内部切分与模型候选（严格 `<= 2026-07-02`）

使用 `scratch/c2_ceiling/hidden/val_hidden_*.npz`（共 `123,836` 个样本，`2025-07-03 .. 2026-07-02`，242 个交易日）：
- 每个交易日内独立标准化输入特征 `x_norm = clip((h - mean_d) / (std_d + 1e-6), -5, 5)`，消除跨日量纲漂移。
- 每日标签：`y_rank = pct_rank(ret10) - 0.5`，每日零均值单位方差标准化 `y_z`。
- 严格时间切分（不重叠 D10 标签）：
  - **训练期**：`2025-07-03 .. 2026-04-30`
  - **隔离带**：`2026-05-01 .. 2026-05-15`
  - **内部验证期**：`2026-05-18 .. 2026-07-02`（用于选超参与最佳 epoch，选定后用固定超参和最佳 epoch 在全量 `2025-07-03 .. 2026-07-02` 重拟合）

对比模型结构：
1. **`RIDGE_BASE`（线性对照）**：复现 `T3` 线性 Ridge（`alpha ∈ {1e4, 1e5, 3e5}`）。
2. **`MLP_COSIC`（非线性截面排序残差网络）**：
   - 结构：`skip = Linear(512, 1)` + `Linear(512, 128) → LayerNorm → SiLU → Dropout(p) → Linear(128, 1)`（零初始化残差末层或小权重初始化）。
   - 损失函数：按交易日整组 batch 计算 `L = (1 - cos_sim(pred_d, y_z_d)) + 0.1 * MSE(pred_d, y_z_d)`，直接最大化日度截面排序相关性。
   - 内部验证选型网格：`weight_decay ∈ {1e-2, 5e-2}` × `dropout ∈ {0.3, 0.5}`（`AdamW lr=1e-3`, `max_epochs=25`, 3 个 seed 平均集成）。

## 3. 65 天窗口检验对照（`2026-07-17 .. 2026-10-23`，对齐 `C2 16 路径 T=0.65, p=0.80`）

- 基线：`C2`（16 路径中位数）
- 对照线：`RIDGE_BASE` 与 `FUSE_RIDGE_C2`（`0.5 * rank(C2) + 0.5 * rank(RIDGE_BASE)`）
- 主候选：`MLP_COSIC` 与 `FUSE_MLP_C2`（`0.5 * rank(C2) + 0.5 * rank(MLP_COSIC)`）
- 同步报告：65 天整体 Rank IC、7–8 月（A 段）与 9–10 月（B 段）分月/分段 IC、中性化 IC、前 10%/前 10/前 20 超额、5 日块 bootstrap 95% 区间，以及 `few_names_backtest`（`k=10, 20`，`step=10`，30% 缓冲）无门控与叠加宽基门控的扣费净收益与最大回撤。
