## 1. 核心设计验证与两阶段突破

1. **Straight-Through Estimator（`STE`）穿透 `dep_layer(s2)` 在 `L=30` 窗口打破历史“微调即退化”魔咒**：
   - 在之前 `G28/G31` 中，直接微调模型常在 `VAL_SEL step=0` 即见顶回落；本次 `G40` 通过 `TailAwareMiniDepAdapter`（`freeze_until=2`，仅解冻 `transformer[2..3] + norm + dep_layer + head.proj_s1`，配 `0.08 * KL + 2500 * L2_anchor` + 不对称左尾加权 `tail_penalized_cosic_loss`）实现前向精确等价于 `argmax(s1_logits)`、反向无损回传梯度：
     - **`ft_mini_l30` 在 `VAL_SEL` 显著爬坡**：从 `step=0 (0.0987: cvar=0.1058, fwd=0.0916)` 连续提升至 **`step=240 / 0.74 epoch` 的 `0.1036 (cvar=0.1105, fwd=0.0967)`（`+0.0049`）**；
     - `ft_mini_l45` 在 `VAL_SEL` 峰值锁定 `step=0 (0.0975)` 并作为强锚点保留，双卡严格由 `VAL_SEL` 择优验证了多窗并行微调的必要性。
2. **微调后单核 `FT-Mini` 展现惊人独立战斗力与极低 `C2` 相关性（`0.25..0.38`）**：
   - 仅依赖单一 `FT-Mini L=45` 端到端输出的 **`G40_FTMINI_L45_E2E`** 与 `C2` 相关性仅 **`0.247`**，单头轰出 **`Rank IC 0.1927, NIC 0.1298, liq10 +3.59%`**，10 相位 **`k=10` 扣费净收益 `+24.79% (DD -10.09%, Calmar 2.457, 10/10)`**，与 `C2` 简单等权融合 **`FUSE_G40_FTMINI_L45_E2E`** 达到 **`IC 0.2078 (1.92), 100.0% 正天数, k=10 +28.36% (DD -12.64%, Calmar 2.243)`**；
   - 基于微调后 `4.1M FT-Mini` 抽出的闭式岭回归头 **`G40_FTMINI_RIDGE_CVAR / NOWHIPSAW / FWD5_10`** 将高流动性 Top-10 超额推至 **`liq10 = +4.49% / +4.47% / +4.42%`**，全面刷新项目流动性头部纪录；
   - **`FUSE_G40_FTMINI_RIDGE_NOWHIPSAW`** 拿下 **`IC 0.2120 (ICIR 2.08), 100.0% 正天数, k=10 +25.28%, k=20 +22.41%`**。
3. **`FT-Mini + Frozen C2`（`5918d`，物理零 `Base/PTS`）联合抗跌与后半段稳健突破**：
   - **`G40_JOINT_RIDGE_NOWHIPSAW`**：单头即拿到 **`IC 0.2110 (NIC 0.1456)`、`k=10 +21.48% (DD -8.30%, Calmar 2.587)`、`k=20 +21.07% (DD -8.29%, Calmar 2.541)`**；
   - **`FUSE_G40_JOINT_RIDGE_FWD5_10`**：达到 **`IC 0.2180 (ICIR 2.11), 100.0% 正天数, Seg A/B 0.229/0.200, NIC 0.1382, k=10 +24.29%`**；
   - 非线性左尾门 **`G40_JOINT_LGBM_CVAR10`**（`VAL_SEL=0.1323`）与 **`G40_JOINT_TAILSHIELD_CVAR_SHIELD35 / XSTOCK_TAIL`** 在 OOS 后半段实现暴力逆转（**`Seg B = 0.205 / 0.231 / 0.227` 远超 `Seg A 0.128 / 0.110 / 0.139`**），其中 **`G40_JOINT_LGBM_CVAR10`** 单头将 `k=10 / k=20` 最大回撤双双锁定至 **`-6.94% / -6.21%`（`+12.48% / +12.25%, Calmar 1.798 / 1.973`）**。
4. **客观保留短板样本（严格忠实记录）**：
   - 联合空间上的低正则纯线性左尾锚（`G40_JOINT_RIDGE_CVAR / CRASHENTRY / LIQCVAR`, `alpha=1e6`）因维度拼接后过度拟合极端尾样本，OOS 仅 `0.1200 .. 0.1349`（`k=10 +1.64%..+7.75%`），应在 Wave 5 总集成中剔除，优先采用高正则 **`NOWHIPSAW / FWD5_10`**（`alpha=1e9`）及非线性 **`DualMLP / XStockTail / LGBM_CVAR10`**。
