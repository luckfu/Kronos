## 1. 一句话结论（五项全新科学发现）

1. **首次验证 `dep_layer (s2)` 条件隐状态具备极强正交与零衰减潜力**：
   - 仅提取 `Kronos-mini (4.1M)` 在 `L=45` 上由 `argmax s1` 驱动的 `dep_layer` 末位向量（仅 **`256d`**！），**`G31_MINI_L45_DEP_S2`** 单头即拿下 **`IC 0.1950 (ICIR 1.78, 100.0% 正天数, 中性化 0.1292)`**；
   - 与 `C2` 等权融合后 **`FUSE_G31_MINI_L45_DEP_S2`** 达 **`IC 0.2063 (ICIR 2.28)`** 且 **`Seg A/B = 0.209 / 0.202` 几乎零衰减**、`k=10 +23.28% (10/10 全赢)`、`k=20 +21.01% (10/10 全赢)`！
2. **仅 8 个零采样 `s1` 1 步解析分布统计量（`exp_ret / exp_oc / std_c / exp_hl / prob_up / ent / max_p / top5_p`）单头即击败 16 路径 AR 基线 `C2`**：
   - **`G31_MINI_S1_STATS`**（仅 `8d`！）单头拿下 **`IC 0.1528`、`中性化 0.1002`、`k=10 +14.37% (Calmar 1.130)`、`k=20 +16.12% (Calmar 1.353)`**，且与 `C2` 秩相关仅 **`0.123`**（全系列最低！）；
   - 仅用这 8 个标量与 `C2` 融合（`FUSE_G31_MINI_S1_STATS`），即可将 `C2` 的 Rank IC 从 `0.1428` 直接拉升 `+0.0493` 至 **`0.1921 (ICIR 2.03, 100.0% 正天数)`**！
3. **极简轻量生产双核（仅 `C2 + 4.1M Mini`，零 `Base`、零 `PT-Small`）刷新两项全系列线性单头纪录**：
   - **`G31_MINIC2_JOINT_RET5`**（`Mini + C2 L=45` 联合、`ret5` 目标，**无 `C2 AR`**）：刷新全系列线性单头 Rank IC 新纪录 **`0.2043 (ICIR 1.72, 95.4% 正)`**；融合后 **`FUSE_G31_MINIC2_JOINT_RET5`** 达 **`IC 0.2111 (ICIR 2.26, Seg A/B = 0.216 / 0.204 极均衡)`**；
   - **`G31_MINIC2_JOINT_REGIME`**（**无 `C2 AR`**）：刷新全系列单头中性化 IC 新纪录 **`0.1412`**（以仅 `4.1M Mini + C2` 超越 `102M Base` 的 `0.1390`！），单头即实现 **`k=10 +22.73% (最大回撤仅 −9.13%, Calmar 2.490)`**、`k=20 +20.78% (回撤 −9.13%, Calmar 2.275)`；融合后 **`FUSE_G31_MINIC2_JOINT_REGIME`** 达 **`IC 0.2113`、`k=10 +24.12% (Calmar 2.074)`**；
   - **`G31_MINIC2_JOINT_DECAY365`** 单头将 `k=10 / k=20` 最大回撤压缩至 **`−8.63% / −8.51%`（Calmar `2.385 / 2.205`）**。
4. **零新增权重升级（仅复用现有线上 `C2` 权重）再上台阶**：
   - **`G31_C2_L45_RICH_REGIME`** 单头 **`IC 0.1909`、中性化 `0.1342`**（较 G28 的 `0.1265` 大幅抬升）；融合后 **`FUSE_G31_C2_L45_RICH_REGIME`** 达 **`IC 0.2062 (ICIR 2.25, 100.0% 正, Seg A/B 0.213/0.196)`**、`k=10 +19.32% (Calmar 1.587)`。
5. **两项清晰科学验证（`volnorm10` 与 `Mini` 微调）**：
   - **波动率标准化目标 `volnorm10`**（`ret10 / vol20`）在验证集创全系列最高 `val_ic = 0.0873`，且显著降低与 `C2` 相关性（`0.224 vs 0.262`），使 **`FUSE_G31_MINI_L30_45_RICH_VOLNORM`** 在 OOS 上反超 `MULTI`（`IC 0.2072 [100% 正] vs 0.2048`，`k=10 +27.26% [Calmar 2.095] vs +23.50%`）；
   - **`Kronos-mini (4.1M)` 顶层梯度微调**：验证集 `val_ic_raw` 在 `step 0` 即达峰（`L=45: 0.0823`, `L=30: 0.0848`），表明冻结预训练 `Mini` 表征本身已最优（`val_ic_orth` 虽在 `ep 2.0` 从 `0.0592` 升至 `0.0668`，但 raw IC 略有回落）；对应 `step 0` 5 块池化岭回归 `G31_MINI_L45_FT_RIDGE_POOL` 单头拿下 **`k=20 +23.66% (Calmar 2.294)`** 与 **`liq10 +4.17%`**。
