# GPU 探索 G1 Pre-registration：全市场（~5,189 股）多层级 × 双尺度隐状态与正交秩回归（2026-11-15）

**状态**：事前登记（早于 G1 Kaggle GPU Kernel 推送及任何 OOS 计算）。  
**研究纪律**：严格不触碰 `2026-10-24+` 封存验收窗口；所有特征组合与 Ridge 正则化超参 `alpha` 仅在 `<= 2026-07-02` 内决定（训练集 `train_data.pkl 2021-01-04..2026-04-30`；隔离期 `05-01..05-15`；选型验证集 `val_data.pkl 2026-05-18..2026-07-02`），随后用选定超参在 `<= 2026-07-02` 全量重拟合并一次性评测 `2026-07-17 .. 2026-10-23`（65 天，335,312 样本）。

---

## 1. 核心假设（为什么比现有 `head_val_alpha1e4` 更强）

当前最佳线性基准 `FUSE_RIDGE_C2`（65 天 OOS `Rank IC = 0.1503`，中性化 IC `0.0985`，`k=20` 扣费净收益 `+15.49%`、最大回撤 `-12.97%`、Calmar `1.194`）所用的 `head_val_alpha1e4.npy` 仅拟合于 **516 只验证股票、单一年份（`2025-07..2026-07`，123,836 行）** 的单一向量（最后一层末位 `t=119`）。本实验在 **2× Tesla T4 GPU** 上检验三个尚未触及的信息增量：

1. **H1a（全市场样本量与跨周期外推）**：用全市场约 5,000+ 只股票、横跨 2021–2026 多轮牛熊切换期（每 3 个交易日采样一个完整截面）替代仅 516 只单年样本。
2. **H1b（多层级 + 局部动态 + 双回看尺度 `L=60 / L=120`）**：
   - `L120_LAST`（512d）：`L=120` 最终层末位（对标 `RIDGE_BASE`）；
   - `L120_PRE`（512d）：`layer 5` 末位（注入 `sector/size` 条件层之前的纯量价表征）；
   - `L120_M5`（512d）：最后 5 根 K 线稳态隐状态均值；
   - `L120_DIFF20`（512d）：`h_last - mean(h[-20:])`（20 日潜空间状态动量）；
   - `L60_LAST`（512d）：仅用近 60 天独立归一化窗口重喂冻结 C2 得到的末位表征（检验变长回看视角）；
   - `L60_PRE`（512d）：`L=60` 在条件注入前（`layer 5`）的纯量价表征。
3. **H1c（纯正交化目标训练 `G1_MULTISCALE_ORTH`）**：直接用**当日截面剥离市值分位、行业、`10日反转`后的残差收益秩**训练 3,072 维线性头，再与自回归 `C2 (16p)` 做预注册 50/50 融合，以最大化增量分散化效果。

## 2. 事前锁定的候选臂与评估协议

在验证集 `2026-05-18 .. 2026-07-02`（未见过股票 + 严格时间外）从 `alpha ∈ {1e4, 1e5, 3e5, 1e6, 3e6, 1e7}` 中挑选唯一最佳 `alpha`：

- **`G1_UNIV_LAST`**：`L120_LAST`（512d），检验全市场大样本扩增；
- **`G1_L60_ONLY`**：`L60_LAST + L60_PRE`（1,024d），检验纯 60 日短回看视角；
- **`G1_MULTISCALE_ALL`**：全部 6 组特征（3,072d），检验多层级 × 双尺度联合增益；
- **`G1_MULTISCALE_ORTH`**：全部 3,072d 拟合于因子正交残差秩目标（按验证集中性化 IC 选 `alpha`）。

**融合规则（不调参）**：每个候选分别评估其**单模型**与 **`50/50` 截面百分位秩融合（+ `C2 16路径 T=0.65, p=0.80`）**。

## 3. 对照基线与晋级/淘汰门槛

对照双基线（均来自 `20261115_hidden_ranknet_results.json`）：
- `C2 (16p)`：`Rank IC = 0.1428`，`Neutral IC = 0.0810`，`k=20` 扣费净收益 `+11.47%` / 回撤 `−20.33%` / Calmar `0.564`
- `FUSE_RIDGE_C2`：`Rank IC = 0.1503`，`Neutral IC = 0.0985`，`k=20` 扣费净收益 **`+15.49%`** / 回撤 **`−12.97%`** / Calmar **`1.194`**

**判定标准**：
- 只有当新 `FUSE` 组合在 65 天 OOS 上同时超越 `FUSE_RIDGE_C2`（例如 `Rank IC > 0.152` 且 `Neutral IC > 0.100`，或在 `k=20` 可交易回测中净收益 > `+15.49%` 且 Calmar > `1.194`）时判为真实改进；否则诚实记录为未显著超越现有线性头并转入 G2（端到端微调 C2 顶层 Transformer）。
