# GPU 探索 G19 事前登记：`stride=1` 全密度 `L=45` 三架构联探（`C2 L=120 + PT-Small L=45 [L4,L6] + Base L=45 [L5,L8,L10]`）（2026-11-18）

- 创建时间：2026-11-18
- 硬性纪律：严禁触碰 `2026-10-24+` 封存验收窗；超参选择严格在未见面验证集 `2026-05-18 .. 2026-07-02`，最终全训练期重拟严格截止 `2026-07-02`；OOS 评估窗口 `2026-07-17 .. 2026-10-23`（65 天 / `335,312` 行）。

## 1. 立项依据

1. `G14_BASE_L45_832` 与 `G16_PT_SMALL_L45` 同时在 `L=45` 刷新双模型 `Rank IC`（`0.1951*` 与 `0.1943*`）且同时触及正则网格上界（`1e7` / `3e6`），将四方/五方融合首次推至 `0.2033* / Calmar 2.103`；
2. 此前两者仅在 `stride=2` 上分别拟合、且 `Base L=45` 未曾叠加 G11 有效的 `[L5, L8, L10]` 跨深度特征；
3. 本实验在 `smmt315` 上以 `2021-01..2026-07 stride=1`（`582.8 万` 样本）全密度同时抽取三大骨干：`C2 L=120`（`512d`） + `PT-Small L=45 [L4, L6]`（`1,024d`） + `Base L=45 [L5, L8, L10]`（`2,496d`）共 `4,032d`，并把正则网格上推至 `1e8`，检验单头升级与跨架构各向异性联合上限。
