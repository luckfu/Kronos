## 1. 一句话结论

1. **刷新全系列双模型最高 Rank IC 与最强风格中性化 Alpha**：
   - **`FUSE_G25_BASE_L52_POOL`**（`Kronos-base L=52 [L10_last, L10_m5]` `1,664d`，`alpha=3e8` 内点峰值与 `C2` 等权融合）65 天 OOS Rank IC 高达 **`0.2069`（`ICIR 2.17`，`100.0%` 正天数，配对 `dC2 = +0.0641 [+0.0120, +0.1133]`，中性化 IC `0.1318 / ICIR 1.58`）**；

2. **彻底解开 G19 `Base L=45` 在 `alpha=1e8` 触上限的悬念，且多路加权明显改善尾部实盘收益**：
   - 解除 `1e8` 上限后，多维特征头均精准落在内点峰值 **`alpha = 3e8`（`2,496d`）** 与 **`1e9`（`5,824d`）**；

   - **`FUSE_G25_BASE_L45_ML_DECAY`**（`L=45 [L5, L8, L10]` 时间衰减 + `y_multi`）在 `Base` 家族中拿下最高可交易风险收益比：**`IC 0.2028 (ICIR 2.26)`、`k=10 +23.47%`（`10/10` 全赢，最大回撤仅 `−12.03%`，Calmar `1.952`）**；

## 4. 关键发现：三大模型家族在 `L=45` 上的精准分工

把 **G24 (`PT-Small`)**、**G25 (`Kronos-base`)** 与 **G26 (`Kronos-mini`)** 放在同一把全密度标尺下对比，各架构的优势边界已极其清晰：

1. **`Kronos-base` (`102M`, `d=832`) 擅长截面总体排序与中性化去风格**：`G25_BASE_L52_POOL` 拿到最高中性化 IC（`0.1390`）与最高双模型 Rank IC（`0.2069`）；但在 `k=10` 极端头部收益上（`+17.66%~+23.67%`）略逊于 `PT-Small` 和 `Mini`。
2. **`PT-Small` (`24.7M`, `d=512`) 与 `Kronos-mini` (`4.1M`, `d=256`) 擅长可交易头部收益与夏普/Calmar**：`FUSE_G24_PTS_L45_FULL2560_MULTI` 拿下 **`k=10 +27.67% (Calmar 2.238)`**，而 `FUSE_G26_MINI_PTS_JOINT_RAW` 与 `FUSE_G26_MINI_BAND_RAW` 拿下 **`k=10 +27.42% (Calmar 2.458)`** 与 **`k=20 +25.97% (Calmar 2.384)`**。
3. **跨架构异构集成的巨大潜力**：四个零泄漏独立家族（`C2` + `Mini-2k` + `PT-Small` + `Base`）之间既共享高 OOS 有效性，又拥有不同词表/深度/微调属性的正交性。
