# 数据版本归因 Level 0+1：C2（旧数据）vs Base clean（clean 数据）密封窗拆解

日期：2026-11-04，Asia/Singapore。
口径声明：密封窗 2026-08-03～09-30 为 **REFERENCE 诊断**，不重解码、不调参；C2 预测来自
`wynstonliu/kronos-small-sealed-oos-20260803-20260930` 的历史 shards，Base 为 11-04 固定种子
（20261104）重跑的 `main_best_s516`。身份按 identity 全对齐（213,564 × 2）。

## 0. Level 0：两版数据的静态 diff

| 维度 | 旧（luckfu，C2 用） | clean（smmt315，Base 用） |
|---|---|---|
| 训练面板行数 | 11,333,997 | 11,070,116（**剔 263,881 个零成交行**） |
| 训练窗口数 | 10,661,560 | 10,397,679（恰好 −263,881） |
| 窗口语义 | 130 连续**原始行**（含停牌日） | 130 连续**成交行**（剔后重排） |
| 切分合同 | 520 val 股 / 2025-07-01~2026-07-02 | **相同** |
| asset_metadata.csv | 851,634,832 B | 同字节数（SHA 未核） |
| symbol_split.csv | 579,519 B | 573,110 B → **已核**：split/sector 归属 0 差异；rows 差异 = 零成交剔除 |
| val_data.pkl | 14,917,561 B | 14,891,189 B → **已核**：520 股 191,223 行逐值一致，字节差只是序列化开销 |
| train_data.pkl | 874,652,807 B | 854,033,265 B → **已核**：抽样 200 股共有日期数值 0 差异；旧版多出的行 100% 是零成交行 |

注意：密封评测包的 `combined_raw.csv` 本身**不含零成交行**（1,631,504 行全 >0），旧包里的
`august_raw.csv` 也没有——所以**零成交剔除影响的是训练期学到的模式，不是评测输入**。
停牌复盘类样本在训练分布里的有无，是候选机制之一。

## 1. Level 1：预测逐层拆解

### 1.1 总量（全 42 天）

| 模型 | D10 日均 IC | 方向 | top10%−bottom10% 日均价差 |
|---|---:|---:|---:|
| C2（旧数据，2505 段） | **0.1116** | 0.5356 | **+2.43%** |
| Base main best@516（clean，909 段） | 0.0284 | 0.5169 | +0.21% |
| Base extend best@175（clean，1084 段） | 0.0247 | 0.5162 | +0.19% |

C2 的截面多空价差是 Base 的 **12 倍**。这不是幅度收缩问题：Base 预测的截面 std 反而**更大**
（0.0765 vs 0.0522），是**排序内容不同**——C2↔Base 逐日预测的 Spearman 相关仅 **0.238**。

### 1.2 逐日结构

- C2 在 **34/42** 天跑赢 Base；Base 为负而 C2 为正的有 **11 天**。
- 逐日 IC 相关 0.517（同涨同跌、幅度不同）。
- 8 月：C2 0.1720 / Base 0.0837；9 月：C2 0.0512 / Base **−0.0269**。**两者都在 9 月衰减，但 Base 直接转负。**

### 1.3 分层（哪里丢的）

| 维度 | 发现 |
|---|---|
| 行业（84 类） | C2 在绝大多数行业占优，无单一行业主因；delta 范围 −0.19 ~ +0.29 |
| 市值十分位 | **每个分位 C2 都赢**，delta +0.04 ~ +0.10，均匀 |
| **当日波动率** | **低波日两者打平（0.11 vs 0.11）；最高波日 C2 0.107 vs Base −0.062** |
| **市场涨跌日** | 下跌日 C2 0.110 / Base 0.064；**上涨日 C2 0.114 / Base −0.008（Base 完全没信号）** |

## 2. 结论

1. **差距是弥散的**（全行业、全市值段都在），不能归因于某类被删样本的局部效应；
2. **差距是制度敏感的**：低波动日 Base 与 C2 打平，高波动日/上涨日 Base 崩掉——clean 线学到的是
   平静市况的排序，丢掉了剧烈行情里的判别力；
3. 训练深度不是主因：Extend 多训 175 段后 OOS 不升反微降（11-04 配对 CI 含 0）；
4. 两条独立 clean 线（Small C03/epoch2/e03b + 本线 Base）同方向劣于 C2，指向**数据版本**本身。

## 3. 机制检验结果

**机制 1（停牌/零成交行）：已证伪。** 按"股票在 2025-07~2026-10 是否有停牌缺口"分层：
无停牌史股票上 C2−Base = +0.0834，有停牌史上 +0.0803——**差异不集中在受影响样本**。

**机制 2 之前，先做决定性隔离：同尺寸数据版本对照。**
e03b = Small + clean 数据，与 C2 同模型尺寸、同窗、同评测协议（同 kernel 输出 shards）：

| 模型 | 数据 | D10 日均 IC | 方向 |
|---|---|---:|---:|
| C2 | 旧 | **0.1116** | 0.5356 |
| e03b | clean | 0.0643 | 0.5287 |
| Base main | clean | 0.0284 | 0.5169 |

- **数据版本效应（Small 尺寸隔离）：0.1116 → 0.0643，Δ −0.047**，C2 在 32/42 天占优，
  且复现同一波动率 pattern（Q1 0.112 vs 0.058，Q5 0.107 vs 0.018）。
- 尺寸效应（clean 上 Small→Base）：0.0643 → 0.0284，Δ −0.036。
- 两个效应同向叠加，数据版本是更大的一项。

**结论修正**：差距的主因**不是"训练不够"也不是某类被删样本**，而是 clean 数据版本本身。
**面板级核验（本节新增）已排除"两版存在未记录数值改动"**：train/val/split 的全部共有内容逐值一致，
唯一差异就是 263,881 个零成交行及其引发的窗口重排（lookback 日历漂移、标签从"未来 10 面板行"
变为"未来 10 成交日"、窗口归一化统计重算）。尺寸增大在 clean 上不但没补回，反而更差。

## 4. 建议的下一步

归因已定位到**数据版本**。继续烧训练没有依据（Extend 已证改善不迁移）。两条路：

1. **查数据本身**：核对两版 symbol_split/val_data/asset_metadata 的 SHA 与内容差异；
   若内容一致，则差异只剩"剔零成交行+窗口重排"，最直接的验证是出一版"只改这一个开关"
   的数据包，Small 短训 60 段对照（~9h GPU，唯一控制变量）。
2. **战术上**：C2 仍是唯一通过密封窗的候选，维持现状；Base clean 线暂停加训。
