## 1. 四项核心实证结论

1. **剔除 `G32` 使极简双核（`C2 + 4.1M Mini`）在实盘净收益、回撤与 Calmar 上全面反超含 `G32` 版本**：
   - 剔除 16 路自回归采样的 `G32_C2_L45_AR16` 并纳入 `G31_mini_l45_dep_s2` 后，[`NOG32_LIGHT_MINIC2_DISTILL6`](finetune/gpu_alpha/eval_no_g32_and_midcycle_shield.py#L101-L108) 在 `step=10, k=10 RAW` 扣费净收益从含 `G32` 对照 `W4_LIGHT_MINIC2_DISTILL` 的 `+23.80%` **升至 `+25.13%`（+1.33 pct，10/10 相位全赢）**，最大回撤从 `-11.75%` **收窄至 `-10.06%`**，Calmar 从 `2.025` **跃升至 `2.497`**，总换手成本降至 `1.60%`；
   - 在 5 日灵敏换仓（`step=5, k=10 RAW`）下反超更加显著：净收益从 `+20.52%` **暴涨 +4.69 pct 至 `+25.21%`**，回撤 `-12.39% → -10.04%`，Calmar **`1.656 → 2.511`**；`step=10, k=20 RAW` Calmar 也刷新至 **`2.525`**（`+23.91%`, DD `-9.47%`）。
   - 同时彻底省去 16 路 AR 序列采样开销，消除“前 5 日冲高、第 6–10 日均值回归反噬”脆弱性。
2. **纳入 `G35_LGBM_CVAR10` + `G38_RIDGE_FWD5_10` 让防爆集成同时拿下最高 IC（`0.2408`）与 `100%` 正 IC 天数（`ICIR 2.14`）**：
   - **`WITHG32_CRASH_SHIELD_CVAR10`**（含 `G32` 对照）：创研究最高横截面 **`Rank IC = 0.2408 (ICIR 2.09)`、`100.0%` 正天数、`Seg A/B = 0.238 / 0.247`（后半段反升）、Neutral IC `0.1500`**；`step=5, k=10 RAW` 下轰出 **`+25.27%` 扣费净收益 / `-7.90%` 回撤 / Calmar `3.199`**；
   - **`NOG32_CRASH_SHIELD_CORE`**（零 `G32`）：取得全系列最高稳定性 **`ICIR = 2.14` 与 `100.0%` 正 IC 天数（`Seg A/B = 0.227 / 0.239`）**，`step=10, k=10` 回撤仅 **`-9.39%`**，`step=5, k=10` 回撤压至 **`-7.55%`（`+19.24%`, Calmar `2.549`）**。
   - 但客观反面信号是：仅靠 Wave 3/4 成员、不含 `G32` 的纯 `C2-Only`（`NOG32_C2ONLY_DISTILL5`）`IC 0.2018 / k=10 +13.59%` 仍明显弱于 `W3_C2ONLY_FULL4 (0.2277 / +19.77%)`；且重型左尾护盾组在单头左尾叠加过深后 `k=10` 收益低于极简双核，印证正在 Kaggle 训练的 **`G39`（3-Target 左尾/延续蒸馏进 `C2-Only/Mini+C2`）与 `G40`（`Mini STE dep_layer` 微调）** 是关键补缺拼图。
3. **仅在换仓日生效的混合门控 `G_HYBRID_MIN`（不叠加 `MCB`）是性价比最高的主干护盾**：
   - 65 天 OOS 档位分布：`G_BREADTH {0:20, 1:13, 2:32}`、`G_BREADTH_VEL {0:25, 1:26, 2:14}`、`G_HAZARD_G38 {0:25, 1:28, 2:12}`、`G_HYBRID_MIN {0:30, 1:25, 2:10}`；
   - 对 **`NOG32_LIGHT_MINIC2_DISTILL6`**：在 **`step=5, k=10 G_HYBRID_MIN`** 下平均仓位仅 `31.2%`，却斩获 **`+19.99%` 扣费净收益 / `-5.26%` 最大回撤 / Calmar `3.801`**（交易费仅 `1.89%`）；`ENS_W2F_C2_MINI29` 也高达 **`+21.77% / -6.36% / Calmar 3.425`**；`step=10, k=20` 下 `NOG32_LIGHT` 同样达到 `-4.91%` 回撤与 `2.832` Calmar。
4. **客观评估持仓中日度熔断 `MCB` 的收益/回撤两面性与 `+10bp` 压力测试**：
   - **回撤极值压缩**：`G_HYBRID_MIN_MCB` 成功把极端回撤进一步锁定在 `-3.48% .. -5.21%` 区间——`W4_LIGHT_MINIC2_DISTILL (step=5, k=10)` 达到 **`+18.71% / -4.52% / Calmar 4.138`**，`WITHG32_CRASH_SHIELD_CVAR10 (step=10, k=20)` 创全场最低回撤 **`-3.48%`**；若上游毫无门控（`RAW_MCB`），`MCB` 也能将裸跑 `C2` 回撤砍半（`-22.09% → -10.72%`）。
   - **交易摩擦代价**：因 `MCB` 只允许单向向下棘轮减仓且禁止同周期复仓，`RAW_MCB` 平均每相位触发 `8.5` 次（`step=10`）至 `14.2` 次（`step=5`），总费用飙升至 `3.7% .. 7.7%`，净收益显著低于原生换仓门控；只有在先经 **`G_HYBRID_MIN`** 过滤后，`MCB` 触发次数降至 **`3.1` 次（`step=10`）/ `4.2` 次（`step=5`）**，总费用回到 `1.2% .. 2.4%`。
   - **`25bp + 滑点`（+10bp 单边加压）结论**：高频熔断 `STRESS25BP_RAW_MCB` 因成本涨至 `5.0% .. 9.9%` 导致多组策略接近零收益甚至微负，证明**切勿单独使用无前置门控的高频日内降档**；而 **`STRESS25BP_G_HYBRID_MIN_MCB`** 表现极具韧性：`step=5, k=10` 下 `W4_LIGHT` 仍稳守 **`+17.89% (-4.80% / Calmar 3.725)`**、`NOG32_LIGHT` 稳守 **`+14.75% (-5.46% / Calmar 2.702)`**（`step=10, k=10` 为 `+9.40% / Calmar 1.816`）。

## 4. 对 Wave 5 与 12 月平行封存观察轨的直接指导

1. **生产 / 轻量化观察轨定型**：去掉 `G32` 后的 **`NOG32_LIGHT_MINIC2_DISTILL6`** 已实现“零重型底座 + 零 AR 采样反噬 + `step=5` 下 Calmar 2.511 (RAW) / **3.801 (`G_HYBRID_MIN`)**”；接下来 `G39`（3-Target 左尾/延续蒸馏）与 `G40`（`Mini STE dep_layer` 微调）将在此骨架上叠加后半段延续与 `C2-Only` 抗跌加固。
2. **执行风控定型**：将 **`G_HYBRID_MIN`（换仓日取 `min(G_BREADTH_VEL, G_HAZARD_G38)`）为主护盾、`G_HYBRID_MIN_MCB` 为极值防爆对照组** 写入平行封存评测脚本 [`eval_sealed_secondary_w4w5_dec.py`](finetune/gpu_alpha/eval_sealed_secondary_w4w5_dec.py)，既验证无泄漏下 `5%~6%` 极端回撤锁仓，也严防高频盲目熔断被手续费侵蚀。
