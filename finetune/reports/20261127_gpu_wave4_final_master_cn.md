## 1. 全景核心突破与事前检验对照表（65 天 OOS）

对照 [`20261127_gpu_wave4_g35_g38_prereg_cn.md`](20261127_gpu_wave4_g35_g38_prereg_cn.md) 第 3 节的 4 项事前验收集指标，Wave 4 交出“**三项重大突破 + 一项反面证伪果断淘汰**”的硬核答卷：

1. **单模型历史纪录刷新（`G35`）**：
   - [`20261127_gpu_g35_result_cn.md`](20261127_gpu_g35_result_cn.md) 的 **`G35_LGBM_CVAR10`** 单模型直接轰出 **`Rank IC = 0.2448 (NIC 0.1495, Seg A/B = 0.204 / 0.318)`**，不仅击败前单模型冠军 `G30_QUAD_LGBM_RET5`（`0.2343`），也一举反超 Wave 3 全家桶集成最高纪录（`0.2436`）；同时 **`G35_TAILSHIELD_CVAR_FLOOR`** 在不门控情况下将单头回撤压到 **`-7.84% / -6.55%`**。
2. **赛道 B 极简双核（`C2 + 4.1M Mini`，零 `Base`/`PTS`）刷新双项总冠军纪录（`G37`）**：
   - **`W4_LIGHT_MINIC2_DISTILL`**（[`20261127_gpu_g37_result_cn.md`](20261127_gpu_g37_result_cn.md) 物理零重型底座推理）创下全项目历史最高 **`liq10 = +4.28% / liq20 = +4.17%`** 以及空仓期 10 相位 **`k=20` 净收益 `+24.69% (DD -10.53%, Calmar 2.346, 10/10)`**，超越 `W3_LIGHT_C2AR_MINIC2_5WAY`（`+22.59% / 2.227`）与 `W3_FLAGSHIP_5PILLAR_WITH_S1S2`（`+21.12% / 2.282`）；
   - 赛道 A（零新增权重 `C2-Only`）：单融合 `FUSE_G37_C2ONLY_DISTILL_RESID` 在 `k=10`（`+20.74%`）超越 `W3_C2ONLY_FULL4`（`+19.77%`），但全截面集成 `IC` 仍由包含 `G32 AR` + `G34 dep_c2` 原始线性锚点的 `W3_C2ONLY_FULL4`（`0.2277`）领跑（`W4_C2ONLY_DISTILL_CORE` `0.2115`）。
3. **赛道 D 防暴跌零衰减集成 + 期限结构 + `G38` 危害度执行门控创历史最高 Calmar**：
   - **`W4_CRASH_SHIELD_5PILLAR`**（`G35` 尾险护盾 + `G38 fwd5_10` + Wave 3 核心，不含 `G36`）：以 **`IC 0.2314 (ICIR 2.03, 98.5% 正天数, NIC 0.1445)`** 将前后半段衰减完全归零（**`Seg A / Seg B = 0.233 / 0.230`** vs `W3_FLAGSHIP` `0.244 / 0.192`），在 **`step=5 RAW (k=10)` 拿下 `+23.68% (DD -9.51%, Calmar 2.490, 5/5)`**；
   - **因果危害度门控 `G_HAZARD_G38`（[`20261127_gpu_g38_result_cn.md`](20261127_gpu_g38_result_cn.md)）**：在 **`W4_LIGHT_MINIC2_DISTILL (step=5, k=20)` 斩获全项目历史最高 `Calmar = 2.744`（`+17.53%`, DD `-6.39%`）**，并在 **`W4_CRASH_SHIELD_5PILLAR (step=5, k=20)` 首次将 65d 最大回撤压破 `-5%` 至 `-4.99%`（`+11.71%, Calmar 2.344`）**。
4. **赛道 C 客观证伪并剔除 `G36 LambdaRank / Focal-ListNet`（零粉饰科研纪律）**：
   - [`20261127_gpu_g36_result_cn.md`](20261127_gpu_g36_result_cn.md) 的非对称小盘截断排名损失模型在 `VAL_SEL` 即呈弱拟合（`0.0073..0.0153`），OOS 全线翻负（`IC -0.1665 .. -0.1200`），也拖累了事前把其纳入成员的 `W4_TOPK_SHARP_*`（`0.0137 / 0.0621`）与 `W4_APEX_GRAND`（`0.2137`）。线性 `G36_QUAD_LIQ_RIDGE` 则稳健有效（`FUSE k=10 +23.41%`）。后续工程严禁将 `LambdaRank / Focal-ListNet` 合入生产或封存复核名单。
