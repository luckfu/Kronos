# GPU 探索 G3 Pre-registration：全市场同日截面同业注意力网络（CrossStockPeerRanker）（2026-11-15）

**状态**：事前登记（早于 G3 GPU Kernel 推送及任何 OOS 计算）。  
**研究纪律**：严格不触碰 `2026-10-24+` 封存验收窗口；所有训练仅用 `train_data.pkl <= 2026-04-30`；早停与候选超参仅在 `val_data.pkl 2026-05-18..2026-07-02` 上挑选；`2026-07-17..2026-10-23` OOS（335,312 行）仅作一次性评估。

---

## 1. 核心假设（打破个股独立推理的截面信息盲区）

截至 G2，所有模型（`C2`、`RIDGE_BASE`、`MLP_COSIC`、G1、G2）在神经网络前向传播阶段都是**逐只股票完全独立打分**的：网络直到最终排序或回测选股前，从未见过当日同板块其它股票和全市场风格扩散度。

本实验验证：将全市场每日 `~4,400` 只股票的冻结 `C2` 隐状态 `[N_d, 512]` 作为一个完整的当日集合输入 **`CrossStockPeerRanker`**（线性基准跳跃连接 + 零初始化同日 86 行业原型均值差 `z - mu_sector` + 同日市场均值/离散度交叉注意力），是否能在不依赖个股 ID 记忆的前提下提升排序 Alpha 与 `k=20` 实盘表现。

---

## 2. 事前锁定配置与选型网格

- **特征缓存**：用冻结 `C2` 在 `2x T4` 上抽取 `L=120` 截面 z-score 隐状态 `h_last`（512 维 float16）：
  - 训练集：`2020-07-01 .. 2026-04-30`（隔日采样，约 700 个完整交易日 × ~4,400 股 ≈ 300 万样本）；
  - 验证集：`val_data.pkl 2026-05-18 .. 2026-07-02`（未见过股票 + 隔离期后）。
- **跳连热启动**：先在训练截面统计量上求解 `Ridge(alpha=1e5)` 初始化线性主支路 `skip.weight`，使 Epoch 0 即从全市场线性基准出发，`ctx_head` 零初始化保证零冷启动破坏。
- **损失函数**：`0.70 * CosineIC(score, y_multi) + 0.30 * CosineIC(score, y_orth10)`。
- **验证集挑选网格（仅 4 组，严控选型自由度）**：
  - `(proj_dim, dropout, wd) ∈ {(96, 0.4, 2e-2), (128, 0.4, 2e-2), (128, 0.5, 5e-2), (160, 0.5, 5e-2)}`，每组 15 epochs、3-seed 平均验证曲线按 `0.5 * Val_Rank_IC + 0.5 * Val_Orth_IC` 选出唯一最优 `(cfg, best_epoch)`，在 `<= 2026-07-02` 上训练 3-seed 集成并在 65 天 OOS（`2026-07-17 .. 2026-10-23`）一次性评分。
