## 1. 一句话结论（四项全新科学发现）

1. **`ret20` 长周期标签在 `Kronos-base (102M)` 上一举刷新两项纪录**：
   - **`G33_BASE_L52_RICH_RET20`** 单头拿下 **`IC 0.1896`、中性化 IC `0.1422`**，超越 G31 `Mini+C2` 联合单头的 `0.1412`，刷新全系列单头中性化 IC 新纪录；同时 `G33_BASE_L45_ALL_DEP_RET20` 也以 **`NIC 0.1420`** 紧随其后；
   - 与 `C2` 等权融合后 **`FUSE_G33_BASE_L52_RICH_RET20`** 达到 **`IC 0.2083 (ICIR 2.18, 100.0% 正天数, ΔIC = +0.0655, 95% CI [+0.0146, +0.1137])`**，刷新单架构 `Base` 融合纪录（超越 G25 的 `0.2069`）。
2. **`Kronos-base` `dep_layer (s2)` 独立隐状态（仅 `832d`）即具极强独立 Alpha，叠加全窗多尺度池化 + `Regime` 组合实现最优风险收益**：
   - 仅提取 `Base L=45` 的 `dep_layer(s2)` 单层向量（`832d`），**`G33_BASE_L45_DEP_S2`** 单头即拿 **`IC 0.1849, NIC 0.1293, corr=0.225`**；融合后 **`FUSE_G33_BASE_L45_DEP_S2`** 达 **`IC 0.2044 (ICIR 2.17, 100.0% 正天数)`**；
   - 合并 `dep_layer(s2)` + 多尺度池化（`6656d`）并采用 `Regime` 权重：**`G33_BASE_L45_ALL_DEP_REGIME`** 单头即拿 **`IC 0.1896, NIC 0.1354, k=10 +19.41% (最大回撤仅 −10.48%, Calmar 1.851, 10/10 全赢)`**；融合后 **`FUSE_G33_BASE_L45_ALL_DEP_REGIME`** 达 **`IC 0.2060 (ICIR 2.19, 100% 正), k=10 +21.49% (Calmar 1.645), k=20 +18.52% (Calmar 1.404)`**；
   - `DECAY365` 融合 **`FUSE_G33_BASE_L45_ALL_DEP_DECAY365`** 创 G33 最高 `k=10` 净收益 **`+22.76% (Calmar 1.665, liq10 +3.09%)`**，`FUSE_G33_BASE_L45_ALL_DEP_RET5` 拿下最高 `k=20` 净收益 **`+18.68% (Calmar 1.439)`**。
3. **首次在 `Kronos-base (102M)` 上验证顶层 2-block 温和微调带来真实验证集增益（与 `Mini` 形成鲜明对照）**：
   - 与 G31 `Mini (4.1M)` 微调在 `step 0` 即达峰不同，102M 参数容量的 `Base` 在低学习率顶层双块微调下验证集真实爬升：`L=45` `val_ic_raw` 从 `0.0371 → 0.0544`（`ep 1.5`, `val_ic_orth 0.0388 → 0.0561`），`L=52` 从 `0.0526 → 0.0563`（`ep 1.0`, `val_ic_orth 0.0471 → 0.0591`）；
   - 微调后提特征重fit 岭回归：**`FUSE_G33_BASE_L45_FT_RIDGE_POOL = 0.2055 (100% 正)`**、**`FUSE_G33_BASE_L52_FT_RIDGE_POOL = 0.2056 (ICIR 2.27, 100% 正)`**；其中 `G33_BASE_L52_FT_RIDGE_POOL` 单头将 `k=10` 最大回撤压缩至 **`−10.89% (Calmar 1.343)`**。
4. **`volnorm10` 再次展示最低 `C2` 相关性与最高融合 `ICIR`**：
   - `G33_BASE_L52_RICH_VOLNORM` 与 `C2` 秩相关降至 **`0.193`**（G33 最低），融合后 **`FUSE_G33_BASE_L52_RICH_VOLNORM`** 拿下 G33 最高 **`ICIR = 2.34` 与 `100.0%` 正天数**。
