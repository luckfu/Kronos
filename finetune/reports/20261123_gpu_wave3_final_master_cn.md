## 4. Wave 3 沉淀的五大底层方法论结论

1. **短窗多路径生成轨迹（`C2 L=45 AR`）是独立于所有隐藏层表征的“第一正交支柱”**：仅仅把线上已有 `C2` 的回看窗从 `L=120` 缩到 `L=45`（零训练、推理快 `2.7×`），单模型即从 `0.1428 → 0.1857`，叠加到 Wave 2 冠军上直接再跳 `+0.0105`（`0.2245 → 0.2350`, `100%` 正天数）。
2. **四家族非线性和跨股交互彻底破解了 `Seg B` 风格衰减魔咒**：G30 的 `Quad-LGBM-Ret5`（`Seg A/B = 0.232/0.233`）、`Quad-Resid-CosIC`（`0.194/0.226`）、`CrossStock-Attn`（`0.210/0.199`）证明利用当日横截面分布与市场广度/波动率交互是跨体制稳定性的关键。
3. **`dep_layer (s2)` 与 `s1/s2` 1 步解析分布是极低成本的架构级正交矿脉**：仅 `256d..832d` 的第二解码层就分别产出 `0.1950` / `0.2074` 融合；仅 `10d` 的解析 logit 分布与 `C2` 相关性低至 **`0.085`**，与主干组合后把最大回撤压进 **`−9.20%`（Calmar `2.512`）**。
4. **生产落地已出现“零新权重”与“极简双核”两条黄金路径**：
   - **零新权重路径（`W3_C2ONLY_FULL4`）**：完全不增加任何新模型权重，只复用线上已有 `C2`（`L=120 AR + L=45 AR + L=45 Rich Regime + L=45 dep_s2`），即达 **`IC 0.2277 (Seg A/B 0.234/0.218)`**，超越 Wave 2 四家族集成！
   - **极简轻量双核路径（`W3_LIGHT_C2AR_MINIC2_5WAY` / `W3_LIGHT_C2AR_MINI29_G31`）**：仅新增 `4.1M` 的 `Kronos-mini`（体积极小、单次前向毫秒级），无需加载 `102M Base` 或 `PT-Small`，即同时拿到 **`IC 0.2310`、`NIC 0.1464`、`liq10 +4.27%`、`k=10 +25.40% (Calmar 2.266)`、`k=20 +22.73%`**！
   - **全能旗舰路径（`W3_SUPREME_AR_W2_LGBMRET5` / `W3_FLAGSHIP_5PILLAR_WITH_S1S2`）**：横截面排序天花板 **`IC 0.2436 / NIC 0.1527`** 与实盘风控天花板 **`k=10 +23.13% (回撤 −9.20%, Calmar 2.512)`** 双峰并立。
